## 법인카드 매입·매출 실시간 연동 (2026-07-01 개발책임자 확인 — 범위·방향 확정)
개발책임자 질문(회계담당자 설명: 단말기→**한국정보통신(VAN)**→**여신금융협회 입금확인** 프로세스) → **결정 2건**: **①범위 = 매출(A)+매입(B)+계좌 3-통합** ②**방향 = 현 VAN 한국정보통신(KICC) 매출 먼저 문의**(매입/계좌=팝빌 병행).
- **🔑 용어 구분(답의 핵심)**: 개발책임자 설명 프로세스 = **매출(A, 받는 돈)** 쪽. "우리가 쓰는 법인카드 경비 = 매입(B)"와 **데이터 소스 완전 별개**(섞으면 벤더 오선택).
- **매출(A) 소스 = 여신금융협회 매출거래정보 통합조회(매통조, cardsales.or.kr)** = 카드사별 승인·매입·입금·지급예정일·수수료(회계담당자가 수기 확인하는 그 화면). 실시간 연동 3경로: **①여신협 가맹점 매출거래정보 Open API**(2022 시범→이용대상=금융회사/전자금융업자/핀테크/공공기관 → 일반사업자 직접 자격난, 과금 미공개) **②ASP 경유(현실적)**: 하이픈(hyphen.im) '신용카드 매출내역 조회' 16 API = cardsales 스크래핑 wrap(가맹점/승인/매입/입금/실적) / CODEF '여신협 매입내역' 상품 — 둘 다 **견적형** **③현 VAN KICC 자체**: 이지샵/이지체크 매출관리(실시간 매출·입금예정·정산분석)+개발자센터 docs.kicc.co.kr(VAN·다중정산·RESTful JSON) → **문의 초안 발송 대기**.
- **⚠️ KICC 직접 vs 여신협 경유 분기점**: KICC는 **자기 VAN 경유 매출만** 보유 → 우리 카드매출이 **전부 KICC 단말이면 KICC 직접으로 완결**(최저비용), **다VAN/다단말 섞이면 여신협(하이픈/CODEF)** 으로 전 카드사 커버 필요. **KICC 회신 4번(범위)·5번(비용)이 매출쪽 방향 자동 결정.**
- **매입(B)+계좌 = 팝빌 권고**: 카드사용내역 카드당 월 3천(전일), 계좌 거래내역 계좌당 월 3~6천 → 12계좌+10카드 ≈ **월 6.6~10.2만**(vs CODEF 종량 ≈80만, 8~16배↓). 팝빌 카드=**지출(B)만**(가맹점 매출 A는 팝빌 미제공→여신협/KICC). 계좌 자동대사 파이프라인 ~90% 구축(SP-09-4). CODEF 배선 완비(#670/#671)나 종량 비쌈.
