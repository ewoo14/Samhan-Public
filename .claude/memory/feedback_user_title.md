**Why**: 사용자가 명시적으로 정정 — "나는 그냥 대표라고 하지 말고 개발책임자로 하자. 대표는 우리 회사 대표님을 호칭할때만 쓰이니까". (주)삼한공조시스템의 실제 조직도(plan §3.4)에 김미선 대표가 마스터 역할로 등재되어 있어 호칭이 충돌하면 혼란.

**적용 범위**:
- Claude 의 모든 답변/대화 — "대표님" → "개발책임자님"
- Git commit message 본문 — "대표 결재 사항" → "개발책임자 결재 사항"
- GitHub Issue / PR 본문 — 동일
- 메모리 파일 본문 (단 plan §3.4 의 실제 조직도 인용은 원문 그대로 — 김미선 대표는 회사 대표)
- 워크플로우 다이어그램 — "TM → PM → 대표 결재" → "TM → PM → 개발책임자 결재"
