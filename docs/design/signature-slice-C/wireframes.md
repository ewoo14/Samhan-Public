### 4.2 인수자 셀 — 서명 있음 / 없음 분기

**서명 있음 (signed_at != NULL)**
```
┌─ 인수자 (≈37×30mm) ┐  ← A4 본문폭 186mm / 5 = 37.2mm 균등 분할
│                    │
│  ╱╲ ╱─╲           │ ← <img src="data:image/png;base64,...">
│ ╱  서명  ╲         │   max-width: 100% (셀 폭 fit); max-height: 18mm;
│           ╲        │
├────────────────────┤
│ 김인수      (8pt)  │ ← 메타 정보 (`--print-signature-meta-*`)
│ 2026/05/05  (7pt)  │
└────────────────────┘
```

**서명 없음 (signed_at IS NULL — 기존 Slice A 디자인 유지)**
```
┌─ 인수자 (≈37×30mm) ┐
│                    │
│                    │
│   (서명란 비움)    │ ← 기존 빈 셀 유지
│                    │
│                    │
│                    │
└────────────────────┘
```

### 4.3 CSS-only 변경 (`feedback_print_design_iteration.md`)

| 변경 | 방법 |
| --- | --- |
| 인수자 셀 안 PNG | `.print-signature-cell img { max-width: 100%; max-height: 18mm; object-fit: contain; }` |
| 메타 폰트 | 기존 `--print-signature-meta-color` / `--print-signature-meta-size` 토큰 재사용 |
| 셀 크기 | grid `repeat(5, 1fr)` + max-width 186mm (A4 본문폭 균등) — Slice A 가 60mm 고정이었다면 본 슬라이스에서 균등 1fr 로 보정 (FE 인계). PNG fit 이 셀 폭에 자동 맞춤 |
| 페이지 break | **변경 없음** — 결재선 영역 `page-break-inside: avoid` 유지 |

기존 결재선 셀 grid 구조는 손대지 않고, 인수자 셀 안에 `<img>` + `<div class="print-signature-meta">` 만 조건부 추가합니다.
