# Print Spec — 분개장 / 시산표 인쇄 양식

본 슬라이스 인쇄 양식은 **2종**:
1. 분개장 (period 별 — 일/주/월 분개 일괄 출력)
2. 시산표 (월별)

기존 `--print-text-base / --print-thead-bg / --print-page-w / -h / --print-page-margin`
(sales-polish-2 토큰) 답습. 신규 인쇄 토큰 **없음**.

---

## 1. 공통 사양

### 페이지

- A4 portrait (210mm × 297mm) — sales-polish-2 답습
- 본문 영역: 186mm × 273mm (margin 12mm)
- 폰트: Pretendard, base 11pt (분개장/시산표 dense 표 → 본문 14pt 보다 작게)
  - 표 헤더 11pt bold
  - 표 본문 10pt (회계 표는 dense)
  - 페이지 머리/꼬리 9pt (`--ink-tertiary`)
- 색상: 흑백 인쇄 가정 (`--print-line-color: #000`, `--print-thead-bg: #F0F0F0`)

### 페이지 머리

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ (주)삼한공조시스템                                          {문서명}        │
│ 사업자번호 123-45-67890                                  출력일: 2026-05-04 │
├─────────────────────────────────────────────────────────────────────────────┤
```

### 페이지 꼬리

```
├─────────────────────────────────────────────────────────────────────────────┤
│                                              {n / total} 페이지            │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 분개장 인쇄 (Period 별)

### 트리거

- JournalListPage 우상단 `[인쇄]` 버튼 (현재 필터 결과 그대로 인쇄)
- TrialBalancePage 에서 별도 진입 X (시산표 인쇄와 분리)

### 양식

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ (주)삼한공조시스템                                              분 개 장    │
│ 사업자번호 123-45-67890                                  출력일: 2026-05-04 │
├─────────────────────────────────────────────────────────────────────────────┤
│ 기간: 2026-05-01 ~ 2026-05-04   상태: 전체   출처: 전체                   │
├──────────┬──────┬──────────────────┬──────┬──────────┬──────────┬─────────┤
│ 분개번호 │ 일자 │ 적요             │ 출처 │   차변   │   대변   │ 상태    │
├──────────┼──────┼──────────────────┼──────┼──────────┼──────────┼─────────┤
│20260504-3│05-04 │5월 임차료 지급   │ 수동 │          │          │ POSTED  │
│          │      │  805 임차료      │      │  500,000 │          │         │
│          │      │    └ 강남빌딩    │      │          │          │         │
│          │      │  102 보통예금    │      │          │  500,000 │         │
│          │      │    └ 국민은행    │      │          │          │         │
├──────────┼──────┼──────────────────┼──────┼──────────┼──────────┼─────────┤
│20260504-2│05-04 │매출 (...)        │ 수동 │          │          │ POSTED  │
│          │      │  110 외상매출금  │      │  820,000 │          │         │
│          │      │  401 상품매출    │      │          │  820,000 │         │
├──────────┼──────┼──────────────────┼──────┼──────────┼──────────┼─────────┤
│ ... (계속)                                                                  │
├──────────┴──────┴──────────────────┴──────┼──────────┼──────────┼─────────┤
│ 합계                                       │5,409,000 │5,409,000 │ ✓ 일치  │
└────────────────────────────────────────────┴──────────┴──────────┴─────────┘

```

### 컬럼 폭 (186mm 본문)

| 컬럼 | 폭 |
|---|---|
| 분개번호 | 22mm |
| 일자 | 14mm |
| 적요 (라인 indent 포함) | 70mm |
| 출처 | 12mm |
| 차변 | 25mm (우정렬, tabular-nums) |
| 대변 | 25mm (우정렬, tabular-nums) |
| 상태 | 18mm |

### 헤더/라인 표시 규칙

- 분개 헤더 행: 분개번호 / 일자 / 적요 (헤더 적요만) / 출처 / 상태 (차/대 빈 칸)
- 라인 행: 적요 컬럼에 `  {코드} {계정명}` (2-space indent)
- 라인 거래처: `    └ {거래처명}` (4-space indent + tree connector)
- DRAFT 분개: 옅은 회색 배경 (`#F8F8F8`)
- REVERSED 분개: line-through (적요/계정명에 적용)

### 페이지 분할

- 분개 단위 atomic — 한 분개의 헤더+라인이 페이지 경계에 걸치면 다음 페이지로 이월
- CSS `page-break-inside: avoid` (분개 그룹 단위)

### 합계 행

- 마지막 페이지 footer 위에 표시
- 차변 합계 = 대변 합계 검증 마크 ("✓ 일치" 또는 "✕ N 차이")

## 3. 시산표 인쇄 (월별)

### 트리거

- TrialBalancePage 우상단 `[PDF 인쇄]` 버튼

### 양식

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ (주)삼한공조시스템                                              시 산 표    │
│ 사업자번호 123-45-67890                                  출력일: 2026-05-04 │
├─────────────────────────────────────────────────────────────────────────────┤
│ 기간: 2026년 05월                                                          │
├──────┬─────────────────────────────┬──────────────┬──────────────┬────────┤
│ 코드 │ 계정명                      │     차변     │     대변     │  잔액  │
├──────┼─────────────────────────────┼──────────────┼──────────────┼────────┤
│ 100  │ 자산                        │  4,820,000   │    320,000   │4,500,000│
│ 101  │   현금                      │    500,000   │     45,000   │  455,000│
│ 102  │   보통예금                  │  3,400,000   │    275,000   │3,125,000│
│ 110  │   외상매출금                │    920,000   │              │  920,000│
│ 200  │ 부채                        │              │  1,200,000   │1,200,000│
│ 201  │   외상매입금                │              │    400,000   │  400,000│
│ 220  │   부가세예수금              │              │    800,000   │  800,000│
│ 300  │ 자본                        │              │  3,000,000   │3,000,000│
│ 400  │ 매출                        │              │    820,000   │  820,000│
│ 500  │ 매출원가                    │    500,000   │              │  500,000│
│ 800  │ 판관비                      │     89,000   │              │   89,000│
│ 900  │ 영업외/법인세               │              │              │       0│
├──────┴─────────────────────────────┼──────────────┼──────────────┼────────┤

```

### 컬럼 폭 (186mm 본문)

| 컬럼 | 폭 |
|---|---|
| 코드 | 14mm |
| 계정명 (그룹/잎 indent 포함) | 90mm |
| 차변 | 30mm (우정렬, tabular-nums) |
| 대변 | 30mm (우정렬, tabular-nums) |
| 잔액 | 22mm (우정렬, tabular-nums) |

### 그룹/잎 표시

- 그룹 행 (100/200/...): bold + 계정명 indent 0
- 잎 행: regular + 계정명 indent 4mm (`  {계정명}`)
- 펼침 옵션: 인쇄 전 `[그룹 펼침]` 으로 모든 잎 노출 / `[그룹 접음]` 으로 그룹 합계만

### 잔액 표시 규칙

- BE raw 데이터: 차변 - 대변 (signed)
- 인쇄 화면: **절대값 + 카테고리 의미 부호 자동** (자산/비용 차변, 부채/자본/매출 대변 — 시산표 관례)
- 영(0) 잔액 행은 옵션으로 숨김 가능 (`[잔액 0 행 표시]` 토글)

### 합계 행

- 차변 합계 = 대변 합계 검증 마크 ("✓ 0" 또는 "✕ N 차이")
- 차이 발생 시 빨강 + 알람 (회계 무결성 위반 — 운영팀 확인 필요)

## 4. CSS print media query

```css
@media print {
  body {
    background: #FFFFFF;
    color: #000000;
    font-family: "Pretendard Variable", Pretendard, sans-serif;
    font-size: 10pt;
  }

  .no-print { display: none !important; }

  .print-page {
    width: var(--print-page-w);
    min-height: var(--print-page-h);
    padding: var(--print-page-margin);
    page-break-after: always;
  }

  .print-table {
    width: 100%;
    border-collapse: collapse;
  }
  .print-table th {
    background: var(--print-thead-bg);
    font-size: 11pt;
    font-weight: 600;
    border: 1px solid var(--print-line-color);
    padding: 4px 6px;
  }
  .print-table td {
    font-size: 10pt;
    border: 1px solid var(--print-line-color);
    padding: 3px 6px;
  }
  .print-table .col-amount {
    text-align: right;
    font-feature-settings: "tnum" 1, "lnum" 1;
  }

  .journal-block { page-break-inside: avoid; }
}
```

## 5. 우선순위

본 슬라이스 인쇄 양식 우선순위:
- **MUST**: 분개장 인쇄 (FE 작업 필수)
- **SHOULD**: 시산표 인쇄 (FE 작업 필수)
- **NICE**: 엑셀 (CSV) export (시산표만 — Slice A 범위, xlsx 변환은 deferred)

PDF 변환은 브라우저 인쇄 → PDF 저장 (별도 PDF 라이브러리 도입 X — Phase 5+ 검토).
