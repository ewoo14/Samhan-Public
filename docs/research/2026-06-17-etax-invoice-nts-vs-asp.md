# 전자(세금)계산서 발급 — 자체 직접 발급 vs ASP 연동 (딥리서치)

> 2026-06-17. 개발책임자 요청 딥리서치(99 에이전트, 인용·adversarial 검증). 맥락: 우리는 하루 수백건(월 수천~만건) 발급 고물량 사업자.

## 결론
**하루 수백건 고물량이어도 ASP(발급대행) 연동이 총비용·리스크 양면에서 자체 직접연동보다 유리.**

## 1. 자체 직접 발급 — 제도적 가능, 진입장벽 큼
- **법적 허용**: 부가가치세법 시행령 §68⑤ — 발급경로 3종: ① 표준인증 ERP/ASP ② 국세청 무료 시스템(홈택스/e세로) ③ 현금영수증 발급장치. 자체 ERP 인정. **미인증 자체발급 경로는 없음.**
- **국세청 표준인증 + 시스템사업자 등록 의무** (국세청고시 제2023-17호, 시행 2023.9.1). 자가사용 in-house ERP 도 인증 대상(제10조).
- **공동인증서(사업자범용/전자세금계산서용/ASP용) 전자서명 필수** — 개인 인증서 불가. 보안카드/생체인증은 홈택스/ARS 수기 전용. → **PKI 전자서명 구현이 자체 구축 난이도 핵심 동인.** 자체 시스템은 홈택스에 공동인증서 공개키+암호화용 DN 등록 의무(고시 §5⑤).
- **익일 전송 의무**: 발급일 다음 날까지 국세청 전송(ERP/ASP 자체발급). 홈택스 발급분은 즉시 자동전송. 고물량=익일전송 배치 인프라 자체구축.
- **가산세**(공급자 부담): 지연전송 **0.3%**(발급 익일 경과~확정신고기한 내), 미전송 **0.5%**(공급가액). 상한 5천만원(중소)/1억(중소외), 고의 무한도. 고물량=절대금액 리스크 큼.

## 2. ASP 발급대행 — 권고
- 공개 종량 단가 **~200~220원/건**(국세청 전송 포함, 별도 전송료 없음): 팝빌(Popbill) 200·스마트빌(SmartBill, **비즈니스온 운영 — 더존 아님**) 220(월 기본 11,000원[1~50건]+초과 220)·Bill36524(더존) 200.
- **고물량은 비공개 대량계약 단가**(검증자 추정 흔히 <50원/건, *medium 신뢰도 — 실견적 필요*). 월 1만건 공개단가 ≈200만~220만원/월이나 협상가 대폭↓.
- **Java 등 모든 HTTP 언어 API + 무료 테스트베드**(바로빌 등) → 본 코드베이스(Spring Boot/Java) 즉시 통합.

## 3. 권고
ASP(팝빌/바로빌 등) **대량계약 견적부터** 받아 자체 TCO(표준인증+PKI 전자서명+익일전송 인프라+가산세 책임+규격변경 상시대응)와 비교. 대부분 ASP 가 싸고 안전. 절충: ASP 시작 → 초고물량 ROI 확인 시 자체 검토. **핵심 변수 = 협상 단가 vs 자체 TCO.**
