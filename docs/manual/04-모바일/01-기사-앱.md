## 1. 앱 소개

`mobile-staff` 어플은 영업직원 (estimate mode) + 배송 기사 (driver mode) **통합 앱**입니다. 기사 모드는 Phase 10 W10-3 신규 추가되었습니다.

| 항목 | 내용 |
| --- | --- |
| **앱 이름** | 삼한공조 견적 (com.samhan.estimate) |
| **플랫폼** | Android / iOS (Expo SDK 53) |
| **배포 방식** | Expo Go (시범) / EAS Build APK (정식) |
| **본 매뉴얼 대상** | driver mode (배송 기사) |
| **연동 backend** | arologis-service (port 8097) — 본인 배차 / 위치 보고 / 서명 |

## 2. 앱 설치

### 2-1. 시범용 — Expo Go

처음 사용 직전 또는 시연용. 정식 운영은 EAS Build APK 권장.

1. **Android** : Google Play 에서 `Expo Go` 검색 → 설치
2. **iOS** : App Store 에서 `Expo Go` 검색 → 설치
3. IT 관리자가 발급한 QR 코드 또는 URL 진입
4. Expo Go 안에서 mobile-staff 자동 다운로드 → 실행

![Expo Go QR 진입](../screenshots/04-모바일/01-driver-app-expo-qr.png)

### 2-2. 정식용 — EAS Build APK (Android)

Phase 11 production 시점부터 정식 배포 예정.

1. IT 관리자가 카카오톡 또는 이메일로 APK 파일 전달 (`samhan-mobile-staff-vX.Y.Z.apk`)
2. 핸드폰에서 [설정] → [보안] → [출처를 알 수 없는 앱 설치] 허용
3. APK 파일 탭 → 설치
4. 홈 화면에서 [삼한공조 견적] 아이콘 실행

![APK 설치 안내](../screenshots/04-모바일/01-driver-app-apk-install.png)

> iOS 정식 배포는 App Store 등록 필요 (Phase 11 후 검토). 현재 iOS 사용자는 Expo Go 만 가능.

### 2-3. 권한 허용 (최초 실행)

앱 최초 실행 시 권한 요청 dialog 가 순차 표시됩니다. **모두 [허용]** 선택해야 정상 동작.

| 권한 | 의무 여부 | 미허용 시 동작 |
| --- | --- | --- |
| **위치(GPS) — 사용 중에만 허용** | 의무 | `GpsBlockedScreen` 노출 (driver mode 진입 차단) |
| **위치(GPS) — 항상 허용 (백그라운드)** | 선택 | foreground 만 동작 (앱 화면 보고 있을 때만 추적) |
| **알림** | 선택 | 푸시 알림 미수신 (Phase 11 후 활성) |

![GPS 권한 요청 dialog](../screenshots/04-모바일/01-driver-app-gps-permission.png)

> 위치 권한은 이후 [설정] → [앱] → [삼한공조 견적] → [권한] 에서 변경 가능.

## 3. 로그인

### 3-1. 영업/기사 mode 토글

앱 진입 시 우상단에 mode 토글이 표시됩니다.

![mode 토글 (estimate / driver)](../screenshots/04-모바일/01-driver-app-mode-toggle.png)

| mode | 화면 | 대상 |
| --- | --- | --- |
| **estimate** (default) | 영업 견적 WebView (legacy v2) | 영업 직원 (SALES) |
| **driver** | 본 매뉴얼 대상 4 화면 | 배송 기사 (DRIVER) |

배송 기사는 [driver] 토글을 선택합니다.

### 3-2. JWT 로그인

driver mode 진입 즉시 로그인 화면이 표시됩니다 ([00-시작하기/01. 로그인](../00-시작하기/01-로그인.md) 의 모바일 흐름과 동일).

| 입력 | 예시 | 비고 |
| --- | --- | --- |
| **사번 / 사용자명** | `김기사` | IT 관리자 발급 |
| **비밀번호** | (8자 이상) | 첫 로그인 후 변경 권장 |

로그인 성공 시 JWT (access token + refresh token) 가 앱 내 `SecureStore` 에 저장됩니다.

> DRIVER 권한 미보유 사용자는 driver mode 토글 선택 시 "권한 없음" 안내 후 estimate mode 로 자동 복귀.

## 4. 오늘 배차 목록 (DriverDashboard)

### 4-1. 진입

driver mode 로그인 직후 `DriverDashboardScreen` 이 첫 화면으로 표시됩니다.

![오늘의 배차 화면](../screenshots/04-모바일/01-driver-dashboard-list.png)

### 4-2. 화면 구성

```
┌─────────────────────────────────────┐
│ 오늘의 배차                          │
│ 본인 배정 vehicle 3대                │
├─────────────────────────────────────┤
│ ┌─────────────────────────────────┐ │
│ │ 차량 #1                  [배정완료] │
│ │ 톤수    1.4톤                    │ │
│ │ 상태    배정완료                  │ │
│ └─────────────────────────────────┘ │
│ ┌─────────────────────────────────┐ │
│ │ 차량 #2                    [출발] │ │
│ │ 톤수    2.5톤                    │ │
│ │ 상태    출발                      │ │
│ └─────────────────────────────────┘ │
└─────────────────────────────────────┘
```

| 항목 | 표시 내용 |
| --- | --- |
| **차량 번호** | `#1`, `#2`, ... (vehicleSequence — UUID 비공개) |
| **톤수** | 1톤 / 1.4톤 / 2.5톤 / 5톤 / 대형 |
| **상태 badge** | 대기 / 매칭중 / 배정완료 / 출발 / 배송완료 / 취소 |

### 4-3. 새로고침

화면을 아래로 끌어내려(pull-to-refresh) 최신 배차를 다시 불러옵니다.

![pull-to-refresh 동작](../screenshots/04-모바일/01-driver-dashboard-refresh.png)

### 4-4. 빈 목록

배정된 차량이 없으면 "배정된 vehicle 이 없습니다" 안내가 표시됩니다. 배차 담당(DISPATCH) 의 카카오톡 배차 발송 후 자동 노출.

### 4-5. 호출 endpoint

내부적으로 다음 API 가 호출됩니다 (참고용 — 사용자 조작 불필요).

```http
GET /driver-app/arologis/dispatches/today
Authorization: Bearer <DRIVER JWT>
```

응답: 배정된 vehicle 배열 (vehicleSequence + tonnage + status). dispatch UUID 는 응답에 포함되지 않음 ([UUID 비공개 원칙](../00-시작하기/03-역할별-권한.md)).

## 5. GPS 위치 추적 (DriverLocationTracking)

### 5-1. 진입

하단 탭 [위치 추적] 선택 → `DriverLocationTrackingScreen` 표시.

![위치 추적 화면](../screenshots/04-모바일/01-driver-tracking-screen.png)

### 5-2. 추적 토글

| 토글 | 동작 |
| --- | --- |
| **OFF (default)** | GPS 미보고. 배차 시작 전 / 휴게 시간 |
| **ON** | 30초 주기로 backend 위치 보고. 배송 운행 중 |

토글 ON 시 즉시 1회 보고 + 이후 30초 마다 자동 보고.

### 5-3. 보고 내용

| 필드 | 설명 |
| --- | --- |
| **latitude / longitude** | 현재 GPS 좌표 (NUMERIC(10,7) ~1.1cm 정확도) |
| **capturedAt** | 캡처 시각 (ISO-8601) |
| **source** | `APP_GPS_ACTIVE` (어플 능동 보고) |

> Phase 10 W10-2 시점에 인성데이타 LBS (외부 vendor) 가 추가되어 `LBS_PASSIVE` source 도 병행 활성 예정.

### 5-4. 호출 endpoint

```http
POST /driver-app/arologis/locations
Authorization: Bearer <DRIVER JWT>
Content-Type: application/json

{
  "latitude": 37.5665,
  "longitude": 126.9780,
  "capturedAt": "2026-05-09T10:30:00+09:00",
  "source": "APP_GPS_ACTIVE"
}
```

### 5-5. 백그라운드 추적

| OS | 동작 |
| --- | --- |
| **Android** | 백그라운드 위치 권한 + 토글 ON 시 화면 OFF 상태에서도 추적 (배터리 소비 증가) |
| **iOS** | 백그라운드 권한 허용 시 동일. 미허용 시 앱 화면 켜져 있을 때만 추적 |

## 6. 인수자 서명 + 배송 완료 (DriverSignature)

### 6-1. 진입

대시보드의 차량 카드 → [정차 목록] → 도착한 정차 → [서명 받기] → `DriverSignatureScreen` 표시.

> 본 매뉴얼은 driver 화면 흐름만 다룹니다. 서명 기능 자체의 상세 (PNG hash / 50KB 가드 / DELIVERED 자동 전이) 는 [02. 전자 서명](02-전자-서명.md) 참조.

### 6-2. 서명 캔버스

화면 중앙의 캔버스 영역에 인수자가 손가락 (또는 stylus) 으로 직접 서명.

![서명 캔버스](../screenshots/04-모바일/01-driver-signature-canvas.png)

| 버튼 | 동작 |
| --- | --- |
| **[지우기]** | 서명 다시 받기 |
| **[캡처]** | 현재 서명 + GPS 위치 1회 캡처 (PNG) |
| **[전송]** | backend 로 서명 + GPS 동시 전송 |

### 6-3. 서명 + GPS 동시 캡처

[캡처] 버튼 탭 시점에 다음이 동시에 캡처됩니다.

1. **서명 PNG** : base64 dataURL (≤50KB)
2. **GPS 위치** : latitude / longitude / capturedAt (정확도 ~1.1cm)

### 6-4. 전송 완료 alert

[전송] 성공 시 다음 alert 가 표시됩니다.

```
전자서명 등록 완료
signatureId = (자동 발급)
slip-service 동기화 완료
```

| 분기 | 의미 |
| --- | --- |
| `slip-service 동기화 완료` | arologis-service + slip-service 양쪽 저장 성공 (`slipBridged: true`) |
| `자체 저장만 완료 (slip-service 미연동)` | arologis-service 만 저장 (slip-service 일시 장애 등) |

### 6-5. 호출 endpoint

```http
POST /driver-app/arologis/dispatches/{id}/vehicles/{seq}/stops/{stopSeq}/sign
Authorization: Bearer <DRIVER JWT>
Content-Type: application/json

{
  "imageRef": "data:image/png;base64,iVBORw0KGgoAAA...",
  "latitude": 37.5665,
  "longitude": 126.9780
}
```

backend 의 `signature_source` 컬럼은 자동으로 `APP` 으로 기록됩니다 ([02. 전자 서명](02-전자-서명.md) §3 참조).

### 6-6. 슬립 status 자동 전이

서명 전송 성공 → 연관 slip 의 status 가 `DELIVERED` 로 자동 전이됩니다. 영업 / 회계 / 창고 화면에서 즉시 확인 가능.

## 7. GPS 거부 시 (GpsBlockedScreen)

### 7-1. 화면

위치 권한 거부 / 핸드폰 GPS OFF / 위치 정확도 부족 → `GpsBlockedScreen` 이 driver tab 진입을 차단합니다.

![GPS 차단 안내 화면](../screenshots/04-모바일/01-driver-gps-blocked.png)

### 7-2. 안내 내용

```
GPS 위치 정보가 필요합니다

배송 기사 모드는 정확한 위치 보고가 필수입니다.
아래 단계로 위치 권한을 허용해주세요.

1. [설정] 버튼 탭
2. [권한] → [위치] → [사용 중에만 허용]
3. 앱으로 복귀 후 자동 재시도

[ 설정으로 이동 ]
[ 다시 시도 ]
```

### 7-3. 사용자 결정 정책 (2026-05-07)

> GPS 권한 거부 시 driver mode = **사용 불가**. estimate mode 는 영향 없음.
> 백그라운드 권한은 선택 (graceful) — foreground 만 허용해도 driver mode 사용 가능.

## 8. 자주 묻는 질문 + 트러블슈팅

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| driver 토글이 안 보임 | DRIVER 권한 미보유 | IT 관리자에게 ROLE_DRIVER 추가 의뢰 |
| 로그인 실패 — "권한 없음" | 같은 이유 | 동일 |
| 오늘 배차 목록이 비어 있음 | 배차 미수신 / 차량 미배정 | 배차 담당(DISPATCH) 에게 확인 요청 |
| GpsBlockedScreen 이 계속 표시됨 | 위치 권한 거부 / 핸드폰 GPS OFF | 본 §7-2 안내 따름 |
| 위치 추적 토글 ON 후 보고 안 됨 | 네트워크 끊김 / arologis-service 비활성 | 네트워크 확인 후 재토글, 지속 시 IT 문의 |
| 서명 전송 실패 — "PNG too large" | 50KB 초과 | 서명 다시 받기 (캔버스가 자동 압축) |
| 서명 전송 실패 — "GPS 캡처 실패" | 위치 권한 일시 회수 / 실내 약전계 | 옥외 이동 후 재시도 |
| `slipBridged: false` alert | slip-service 일시 장애 | 자체 저장은 완료 — 자동 재동기화 (Phase 11 후) |
| 백그라운드에서 추적 끊김 (Android) | 배터리 최적화 | [설정] → [배터리] → 본 앱 [최적화 안 함] 설정 |
| 백그라운드에서 추적 끊김 (iOS) | "항상 허용" 미선택 | [설정] → [앱] → 위치 → "항상 허용" |
| 푸시 알림 안 옴 | Phase 11 후 활성 | 현재 미구현 — 카카오톡 별도 안내 |
| APK 설치 안 됨 (Android) | 출처 알 수 없는 앱 차단 | [설정] → [보안] → 본 단계 §2-2 참조 |
| 영업 화면에서 driver 탭 안 보임 | mode 토글 미인지 | 우상단 토글 [driver] 선택 |
