# 04. 현장 사진 첨부

> **Stage 안내**: Stage 3 ⚠️ — Phase 12 step-6 본 PR 에서 7-section 패턴으로 재작성. P1 신규 사진 첨부 미구현. Phase 11+1개월 후 출시 예정.

---

## 1. 구현 상태

| 항목 | 상태 | 비고 |
| --- | --- | --- |
| 검수 사진 첨부 (입고) | ⛔ 미구현 (P1) | P0-9 검수 UI 와 함께 |
| 배송 완료 사진 첨부 | ⛔ 미구현 (P1) | 서명 + 사진 |
| 영업 방문 사진 첨부 | ⛔ 미구현 (P1) | 영업 native 앱 P1-4 와 함께 |
| 이메일 / 카톡 별도 전송 | ✅ 우회 | 임시 |

현장 사진 첨부는 입고 검수 / 배송 완료 / 영업 방문 시 증빙 사진을 슬립에 첨부하는 기능입니다. 모두 미구현 상태이며, 임시 우회로 이메일 / 카톡 별도 전송을 사용합니다.

## 4. 본문

### 4-1. 사진 첨부 미구현 안내

신규 P1 슬라이스로 Phase 11+1개월 후 출시 예정입니다. 정식 출시 후 다음 기능이 제공됩니다.

- 슬립 라인 / 헤더에 사진 다중 첨부 (모바일 카메라 / 갤러리)
- 사진 자동 압축 (1MB 이내)
- 슬립 PDF 인쇄 시 사진 함께 출력
- 영업 방문 보고서 사진 검색

### 4-2. 우회 — 이메일 / 카톡 별도 전송

#### 검수 사진 (입고)

1. 창고 직원이 모바일로 불량 / 차이 부분 사진 촬영
2. 영업 부장 / 회계 / IT 관리자에게 카톡 / 이메일 전송
3. 슬립 적요에 "사진: 메일 첨부 (제목 SLIP-2026-XXXX)" 기록

#### 배송 완료 사진 (DELIVERED)

1. 기사가 모바일로 배송 완료 사진 촬영 (현관 / 박스 / 받는 사람)
2. 영업 직원 / 영업 부장에게 카톡 전송
3. 슬립 비고에 "사진: 카톡 별송" 기록

#### 영업 방문 사진

1. 영업 직원이 거래처 방문 시 사진 촬영
2. 사내 공유 폴더 (`거래처/{거래처명}/사진/{YYYY-MM-DD}/`) 에 업로드
3. 거래처 / 방문일 별 정리

### 4-3. 사내 공유 폴더 정책

- 폴더 위치: 사내 NAS 또는 클라우드 (IT 관리자 안내)
- 파일명 규칙: `SLIP-2026-XXXX_001.jpg`
- 보관 기간: 5년 (한국 회계 표준)

### 4-4. Phase 11+1개월 후 정식 본문 교체

P1 PR 머지 시 본 docs 는 정식 본문으로 교체됩니다.

## 6. FAQ

**Q1. 사진을 영구 보관해야 하나요?**
A. 한국 회계 표준상 거래 증빙은 5년 이상 보관. 사내 NAS 또는 클라우드.

**Q2. 카톡으로 보낸 사진이 사라지면?**
A. 카톡은 4 ~ 6개월 후 자동 삭제 위험. 즉시 PC 로 다운로드 + 사내 공유 폴더 보관.

**Q3. 사진 화질 / 용량 권장?**
A. 1024×768 이상, 1MB 이내 권장. 정식 출시 시 자동 압축 예정.

**Q4. 정식 첨부 기능은 언제?**
A. P1 슬라이스로 Phase 11+1개월 후 출시 예정.

**Q5. 영업 방문 사진은 어디에 보관?**
A. 사내 공유 폴더 `거래처/{거래처명}/사진/{YYYY-MM-DD}/`. 거래처별 정리.
