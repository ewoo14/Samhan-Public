# 08-실시간-협업 / 09. 적용 범위 (Stage 4)

> ✅ **구현 상태** — Phase 12 시리즈 종결. 17 service 중 13 service (audit 대상) + 50+ desktop page + mobile-staff 일괄 적용. PR-H4a (shared module) → PR-H4b (BE 13 service) → PR-H4c (FE 50+ page + mobile) 시리즈 완성.
>
> **본 docs 는 무엇인가요?** — Phase 12 실시간 협업 5종 패턴 (SSE 동기화 + audit overlay + 수정 횟수 + 복원 + 잠금/요청) 이 어느 service / 어느 page / mobile 의 어디에 적용되어 있는지 종합 매트릭스를 제공합니다.

---

## 대상 독자

- **개발책임자 / IT 관리자** — 어느 화면이 적용 완료인지 종합 점검
- **MASTER / MANAGER** — 운영자 교육 시 적용 화면 일괄 안내
- **모든 운영자** — 본인이 자주 사용하는 화면이 적용되었는지 확인

## 4. 미적용 영역 / 후속 검토

### 4-1. 의도적 미적용

다음은 정책상 의도적 미적용:

| 화면 / 기능 | 미적용 사유 |
| --- | --- |
| `/login` 로그인 / `/register` 등록 | 인증 자체는 audit 대상 아님 (단, 로그인 성공/실패는 logging-service 별도 기록) |
| `/admin/dashboard` 위젯 설정 (잠금) | 위젯 layout 변경은 잠금 적용 제외 (개인 설정) |
| `/admin/logs` 조회 (잠금) | 읽기 전용 — 잠금 무관 |
| 인쇄 미리보기 (`/print/*`) | 인쇄 자체는 audit 영향 없음 |
| Stage 3 placeholder docs | 미구현 안내만 — Phase 11 후 정식 화면 추가 시 Phase 12 패턴 자동 적용 |

### 4-2. 후속 PR 검토 항목

| 항목 | 검토 시한 | 비고 |

## 5. 운영 변경 안내 (이전 vs Phase 12 시리즈)

| 측면 | 이전 (Phase 12 이전) | 변경 (Phase 12 시리즈) |
| --- | --- | --- |
| 적용 service | slip-service 부분 | 13 service 일괄 (인프라 4 service 제외) |

| 일관 패턴 | 각 화면별 다름 | shared-realtime module (PR-H4a) 로 100% 일관 |
| BE 변경 | 화면별 다른 audit 컬럼 | shared `audit_log` table + `samhan.realtime.*` SSE 표준 |
| FE 컴포넌트 | 화면별 다른 layout | `AuditOverlay` / `SlipEditRequestDialog` / `userColorHash` design-system 통일 |

## 6. FAQ

| 질문 | 답 |
| --- | --- |
| 이 화면이 적용되어 있는지 어떻게 확인? | 우측 상단 "수정 N회" badge 가 노출 가능한 상태 (또는 0회 hidden) → 적용 확인 |
| 적용 안된 화면에서 수정하면? | audit log 누적 안됨 + SSE 알림 없음. Phase 13 후보 화면이거나 의도적 미적용 |
| 나중에 추가되는 service / page 도 자동 적용? | shared-realtime module 사용 시 자동 — 새 service/page 도입 시 `@SamhanRealtime` annotation + `<AuditOverlay>` 적용으로 일관 |
| 카테고리 통계 dashboard 는 언제? | Phase 13 검토 — 운영 1개월 데이터 누적 후 결정 |
| mobile-staff 의 모든 화면이 적용? | 슬립 / 배차 / 검수 / 검토 / 서명 모두 ✅. 설정 화면은 적용 대상 아님 |
| 17 service 중 13 service만 적용된 이유? | 인프라 4 service (auth/gateway/eureka/config) 는 데이터 처리 안함 |
| 적용 안된 page 가 있다면? | `docs/uiux/phase12/H4c-fe-audit-overlay-rollout.md` §3 (제외 사유 명시) 또는 IT 관리자에게 신청 |
