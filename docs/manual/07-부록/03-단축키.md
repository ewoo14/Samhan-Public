# 07-부록 / 03. 단축키 (Stage 3)

> **대상 독자**: desktop Electron 어플 사용자 (영업 / 창고 / 회계 / MASTER)
> **참고**: 모바일 어플 (RN Expo) / 거래처 PWA 는 단축키 미지원
> **연관 메모리**: `feedback_role_naming_full.md` (ROLE 풀네임 의무)

## 1. 글로벌 단축키 (어플 전체)

| 단축키 | 동작 | 비고 |
| --- | --- | --- |
| `Ctrl+S` | 저장 | 모든 입력 폼 — DRAFT 저장 |
| `Ctrl+Enter` | 저장 + 발송 | 슬립 발행 화면 — SAVED → SENT |
| `F3` | 검색 | 사이드바 globalsearch 또는 list 화면 검색 |
| `F5` | 새로고침 | 현재 화면 데이터 reload |
| `Ctrl+R` | 새로고침 (대안) | F5 와 동일 |
| `Ctrl+Shift+R` | 강력 새로고침 | 캐시 무시 + reload |
| `F11` | 전체화면 토글 | Electron full-screen |
| `F12` | 개발자 도구 | F12 → Console / Network 디버깅 |
| `Ctrl+P` | 인쇄 | 인쇄 미리보기 (Edge 표준) |
| `Ctrl+W` | 현재 탭 닫기 | (P3 backlog — 미구현) |
| `Ctrl+Q` | 어플 종료 | macOS 표준 |
| `Alt+F4` | 어플 종료 (Windows) | OS 표준 |
| `Esc` | dialog 닫기 | 모든 modal / popup |

## 11. 운영자 권장 단축키 5개

가장 자주 사용 — 외워두기 권장:

1. **`Ctrl+S`** — 저장 (모든 화면)

## 12. 단축키 충돌 / 미작동 시

### 12-1. 다른 어플의 단축키와 충돌

OS 차원 단축키 (Win + 키) 가 본 어플 단축키를 가로채는 경우:
- 회사 보안 어플 (예: V3 / Trellix) → 보안팀 협의
- IME (한국어 입력기) → IME 단축키 변경

### 12-2. 단축키 미작동

- 화면 포커스가 다른 곳에 있는 경우 (예: dialog 위) — 메인 화면 클릭 후 재시도
- 키보드 자체 문제 — 다른 키보드로 재시도
- 어플 재시작
- IT 관리자 보고
