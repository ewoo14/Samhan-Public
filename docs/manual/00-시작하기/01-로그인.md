# 01. 로그인하기

> **대상 독자**: 처음 Samhan Public 를 사용하는 모든 직원 (영업/창고/회계/배차/기사)
> **소요 시간**: 약 3분
> **사전 준비**: 본인의 로그인 ID, 초기 비밀번호 (인사 담당자 또는 IT 관리자에게 문의)

---

## 이 매뉴얼에서 배울 내용

- Samhan Public 시스템에 접속하는 방법
- 로그인 ID 와 비밀번호 입력 방법
- 첫 로그인 시 비밀번호 변경 절차
- 로그인 실패 시 대처 방법

---

## 1단계 — 로그인 화면 접속하기

회사 PC 의 웹 브라우저(Edge / Chrome 권장)를 열고 아래 주소를 주소창에 입력합니다.

| 환경 | 주소 |
| --- | --- |
| 사내(개발) | `http://localhost:8080` |
| 사내(운영) | `http://[회사 내부 IP]:8080` 또는 `https://app.samhan-air.com` |
| 외부(원격) | IT 관리자에게 별도 안내 |

> 정확한 주소는 IT 관리자가 안내해 드립니다. 한 번 접속한 뒤에는 브라우저 즐겨찾기에 등록해 두면 편리합니다.

![로그인 화면 전체](../screenshots/00-시작/01-login-full.png)

위 화면이 나타나면 정상적으로 접속된 것입니다. 화면이 나오지 않으면 [트러블슈팅](#트러블슈팅) 항목을 참고하세요.

---

## 2단계 — 로그인 ID 입력하기

화면 가운데 **"아이디"** 입력 박스를 클릭한 뒤, 본인의 로그인 ID 를 입력합니다.

- ID 예시: `kimmiseon` (이름의 영문 표기, 모두 소문자)
- ID 는 인사 담당자가 발급해 드립니다.

![로그인 ID 입력 박스](../screenshots/00-시작/01-login-id-box.png)

> 위 그림의 **붉은 박스** 안에 ID 를 입력하세요. 노란 화살표가 입력 위치를 가리킵니다.

**주의 사항**

- ID 는 **대소문자를 구분합니다**. `KimMiSeon` 과 `kimmiseon` 은 다릅니다.
- 앞뒤 공백이 들어가지 않도록 주의하세요.

---

## 3단계 — 비밀번호 입력하기

ID 아래 **"비밀번호"** 입력 박스를 클릭하고 비밀번호를 입력합니다.

- 처음 사용하는 경우 초기 비밀번호: `samhan!2026`
- 보안을 위해 첫 로그인 시 본인이 정한 비밀번호로 **즉시 변경**해야 합니다 (4단계 참조).

![비밀번호 입력](../screenshots/00-시작/01-login-pw-box.png)

> 비밀번호 입력 시 화면에는 점(●)으로 표시되어 다른 사람이 볼 수 없습니다.

---

## 4단계 — 로그인 버튼 클릭

ID 와 비밀번호를 모두 입력했으면 **[로그인]** 버튼을 클릭합니다. 키보드의 **Enter** 키를 눌러도 동일하게 로그인됩니다.

### 4-1. 로그인 성공 시

로그인이 성공하면 메인 화면으로 자동 이동합니다.

![로그인 성공 후 메인](../screenshots/00-시작/01-login-success.png)

메인 화면 사용법은 [02. 메인 화면 살펴보기](02-메인-화면.md) 매뉴얼을 참조하세요.

### 4-2. 첫 로그인 — 비밀번호 변경

초기 비밀번호(`samhan!2026`)로 처음 로그인한 경우, 자동으로 **비밀번호 변경 화면**이 표시됩니다.

1. **현재 비밀번호**: `samhan!2026` 입력
2. **새 비밀번호**: 본인이 정한 비밀번호 입력 (영문+숫자+특수문자 조합 8자 이상 권장)
3. **새 비밀번호 확인**: 동일하게 한 번 더 입력
4. **[변경]** 버튼 클릭

> **중요**: 변경한 비밀번호는 본인만 알 수 있도록 안전하게 보관하세요. 메모지에 적어 모니터에 붙여두는 행위는 절대 금지입니다.

### 4-3. 로그인 실패 시

ID 또는 비밀번호가 틀린 경우 아래와 같은 빨간색 에러 메시지가 화면에 표시됩니다.

> "아이디 또는 비밀번호가 일치하지 않습니다."

이때는 다음을 확인하세요.

- ID 의 대소문자가 정확한지
- 비밀번호 입력 시 한/영 키가 한국어로 잘못 설정되어 있지 않은지
- Caps Lock 이 켜져 있지 않은지
- 5회 연속 실패 시 계정이 일시 잠길 수 있으므로, 3회 이상 실패하면 IT 관리자에게 문의

---

## 5단계 — 로그아웃

업무를 마쳤으면 반드시 로그아웃 후 자리를 비우세요.

1. 화면 **우측 상단**의 본인 이름을 클릭
2. 드롭다운 메뉴에서 **[로그아웃]** 클릭
3. 로그인 화면으로 자동 이동

> 30분 이상 사용하지 않으면 보안상 자동으로 로그아웃됩니다.

## FAQ (자주 묻는 질문)

**Q1. ID 와 비밀번호를 모릅니다.**
A. 인사 담당자 또는 IT 관리자에게 문의하세요. 본인 확인 후 ID 와 초기 비밀번호를 발급받을 수 있습니다.

**Q2. 비밀번호를 잊어버렸습니다.**
A. IT 관리자에게 비밀번호 초기화를 요청하세요. 초기화 후 다시 `samhan!2026` 으로 변경되며, 다음 로그인 시 새 비밀번호로 변경해야 합니다.

**Q3. 첫 로그인 시 꼭 비밀번호를 변경해야 하나요?**
A. 네. 회사 보안 정책상 초기 비밀번호(`samhan!2026`)로는 시스템을 사용할 수 없습니다. 변경하지 않으면 다른 화면으로 이동되지 않습니다.

**Q4. 비밀번호 조건이 있나요?**
A. 권장 사항은 영문 대/소문자 + 숫자 + 특수문자 조합 8자 이상입니다. 너무 단순한 비밀번호(`12345678`, `password` 등)는 거부될 수 있습니다.

**Q5. 모바일에서도 같은 ID/비밀번호로 로그인되나요?**
A. 네. 영업 직원 native 앱, 기사용 mobile-staff 앱 모두 동일한 ID/비밀번호를 사용합니다.

**Q6. 화면이 한글이 깨져서 표시됩니다.**
A. 브라우저의 글꼴 설정을 확인하거나, Edge / Chrome 최신 버전으로 업데이트하세요. 그래도 깨지면 IT 관리자에게 문의하세요.

## 트러블슈팅

| 증상 | 확인 사항 | 조치 |
| --- | --- | --- |
| 화면이 아예 표시되지 않음 | 주소가 정확한지, 인터넷이 연결되어 있는지 | 주소 재확인 → IT 관리자 문의 |
| "서버에 연결할 수 없습니다" 메시지 | 사내 네트워크에 연결되어 있는지 | 유선/Wi-Fi 재접속 → IT 관리자 문의 |
| 로그인 버튼을 눌러도 반응이 없음 | JavaScript 가 차단되어 있는지 | Edge / Chrome 최신 버전으로 변경 |
| 로그인 후 빈 화면 | 권한이 제대로 부여되었는지 | IT 관리자 문의 (역할 확인 필요) |
| 5회 실패 후 잠김 | 계정 잠금 정책 작동 | IT 관리자에게 잠금 해제 요청 |
