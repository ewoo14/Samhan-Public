# 매뉴얼 스크린샷 가이드

본 가이드는 운영자 매뉴얼(`docs/manual/**/*.md`)에 첨부하는 스크린샷의 캡처/주석/저장 표준을 정의합니다. 매뉴얼 작성자는 반드시 본 표준을 따라야 매뉴얼 전체의 일관성이 유지됩니다.

---

## 1. 캡처 도구

다음 중 하나를 사용하세요. 모두 무료이며 회사 PC 에 설치 가능합니다.

| 도구 | 플랫폼 | 권장 용도 |
| --- | --- | --- |
| **Snipping Tool** (캡처 도구) | Windows 11 기본 내장 | 간단한 영역 캡처 |
| **ShareX** | Windows | 박스/화살표 주석 추가, 자동 업로드 |
| **Greenshot** | Windows | 박스/화살표 + 텍스트 주석 |
| **Snagit** | Windows / Mac (유료) | 고급 주석, 이미 보유한 경우만 |

> **권장**: **ShareX** — 무료, 박스/화살표/번호 매김 주석 가능, 단축키 캡처 후 즉시 편집 모드 진입.

### ShareX 단축키 권장 설정

- **Ctrl+Shift+P** : 영역 캡처 후 편집기 열기
- **Ctrl+Shift+W** : 활성 창 캡처 후 편집기 열기

## 2. 주석(박스/화살표) 색상 표준

매뉴얼 전체의 일관성을 위해 아래 색상/굵기를 반드시 지켜주세요.

| 주석 종류 | 색상 (HEX) | 굵기 | 용도 |
| --- | --- | --- | --- |
| **붉은 박스** | `#FF0000` | 2 px | 강조할 입력 박스/버튼 영역 |
| **노란 화살표** | `#FFD700` | 3 px | 클릭 위치/입력 위치 안내 |
| **번호 원** | `#1E90FF` (배경) + `#FFFFFF` (숫자) | 24 px 원 | 단계별 순서 표시 (1/2/3...) |
| **반투명 마스크** | `#000000` 50% 투명 | — | 민감한 데이터 가리기 |

### 좋은 예 vs 나쁜 예

**좋은 예**
- 입력해야 할 박스 1개를 붉은 박스로 강조
- 그 박스 옆에 노란 화살표로 입력 위치 표시
- 단계가 여러 개면 번호 원(①②③)으로 순서 표시

**나쁜 예**
- 화면 전체에 박스가 너무 많아 어디를 봐야 할지 모름
- 색상이 매뉴얼마다 다름 (어떤 매뉴얼은 파란 박스, 어떤 매뉴얼은 초록 박스)
- 화살표가 너무 가늘어 잘 보이지 않음

## 3. 파일명 규칙

```
<섹션번호>-<기능명>-<위치>.png
```

| 요소 | 설명 | 예시 |
| --- | --- | --- |
| **섹션번호** | 2자리 숫자 | `01`, `02`, `03` |
| **기능명** | 영문 소문자 + 하이픈 | `login`, `main-screen`, `sales-register` |
| **위치** | 화면 내 위치 (선택) | `full`, `header`, `sidebar`, `id-box`, `pw-box` |

### 파일명 예시

```
01-login-full.png            -- 로그인 화면 전체
01-login-id-box.png          -- 로그인 ID 입력 박스 (강조)
01-login-pw-box.png          -- 비밀번호 입력 박스 (강조)
01-login-success.png         -- 로그인 성공 후 메인 화면
02-main-full.png             -- 메인 화면 전체
02-main-sidebar.png          -- 사이드바 메뉴 강조
02-main-header.png           -- 헤더 우측 (사용자명+알림)
```

> **금지 사항**: 한글 파일명 (예: `로그인.png`), 공백 (예: `login full.png`), 대문자 (예: `Login.png`).

스크린샷은 매뉴얼 섹션별로 하위 디렉토리에 저장합니다.

```

├── README.md                  -- 본 가이드
├── 00-시작/                   -- 시작하기 관련
│   ├── 01-login-full.png
│   ├── 01-login-id-box.png
│   └── ...
├── 01-영업/                   -- 영업 업무 관련

│   └── ...
```

## 5. 해상도 권고

| 화면 종류 | 권장 해상도 | 비고 |
| --- | --- | --- |
| **데스크탑 (전체 화면)** | 1920 × 1080 | Full HD 모니터 기준 |
| **데스크탑 (부분 캡처)** | 800 × 600 ~ 1200 × 800 | 부분 강조용 |
| **모바일 (전체 화면)** | 1080 × 1920 (세로) | 일반 안드로이드/iOS |
| **모바일 (부분 캡처)** | 800 × 1200 | 부분 강조용 |

> **주의**: 캡처 후 강제 확대/축소 금지. 가능하면 모니터 자체를 1920×1080 으로 설정한 뒤 캡처하세요.

## 6. 파일 압축 (필수)

저장소 용량을 위해 PNG 파일은 반드시 압축한 뒤 커밋합니다.

| 도구 | 방법 |
| --- | --- |
| **TinyPNG** (`https://tinypng.com`) | 웹 업로드 → 자동 압축 → 다운로드 |
| **ImageOptim** (Mac) | 드래그 앤 드롭 |
| **PNGGauntlet** (Windows) | 폴더 단위 일괄 압축 |

> **목표**: 한 장당 **200 KB 이하**, 전체 화면도 **500 KB 이하**.

## 7. 민감 데이터 처리

스크린샷에 아래 정보가 포함되지 않도록 캡처 전 확인하세요. 부득이 포함된 경우 반투명 마스크로 가립니다.

- **개인정보**: 실제 직원 이름, 주민번호, 휴대폰번호, 이메일
- **거래처 정보**: 실제 거래처명, 사업자등록번호
- **금액 데이터**: 실제 매출/매입 금액
- **UUID**: 사용자 화면에 노출되어선 안 되는 내부 UUID
- **로그인 정보**: 실제 비밀번호 (입력 박스에 점●으로 표시되어도 길이로 추측 가능하므로 주의)

### 권장 — 데모 데이터로 캡처

캡처 전용으로 아래 데모 데이터를 사용하세요.

| 항목 | 데모 값 |
| --- | --- |
| 직원명 | `김미선`, `박영업`, `이창고`, `최회계` |
| 거래처명 | `(주)데모상사`, `예시물류` |
| 사업자번호 | `123-45-67890` |
| 휴대폰 | `010-0000-0000` |
| 금액 | `1,000,000원`, `500,000원` |

## 8. 모바일 스크린샷 캡처 방법

### Android

1. **전원 + 음량(-)** 버튼 동시 누름
2. 갤러리 → 스크린샷 폴더에서 PNG 추출
3. PC 로 옮긴 뒤 압축

### iOS (영업 직원 native 앱)

1. **전원 + 음량(+)** 버튼 동시 누름 (Face ID 모델)
2. 또는 홈 + 전원 (Touch ID 모델)
3. 사진 앱 → AirDrop 또는 케이블로 PC 전송

### 에뮬레이터 / 시뮬레이터 (개발용)

- **Android Studio Emulator**: 우측 패널 카메라 아이콘
- **Xcode Simulator**: ⌘+S (자동 데스크탑 저장)

## 9. 캡처 체크리스트

매뉴얼에 첨부하기 전 아래 항목을 모두 확인하세요.

- [ ] 해상도가 권장 사이즈인가?
- [ ] 박스/화살표 색상이 표준(붉은 #FF0000, 노란 #FFD700)인가?
- [ ] 파일명이 규칙(`<섹션>-<기능>-<위치>.png`)을 따르는가?
- [ ] 적절한 디렉토리(`screenshots/<섹션>/`)에 저장했는가?
- [ ] 민감한 정보(이름/번호/금액)가 노출되지 않았는가?
- [ ] PNG 파일 크기가 200 KB 이하인가? (압축 완료)
- [ ] 매뉴얼 본문의 마크다운 경로(`![]()`)가 정확한가?

## 10. 자주 묻는 질문

**Q1. JPG 로 저장해도 되나요?**
A. 안 됩니다. 텍스트가 많은 UI 스크린샷은 PNG 가 화질이 훨씬 깨끗합니다. 사진(카메라)이 필요한 경우만 JPG 허용.

**Q2. GIF 애니메이션은 사용 가능한가요?**
A. 매뉴얼에서는 사용하지 않습니다. 동작 흐름은 단계별 PNG 여러 장으로 표현하세요. (저장소 용량 + 인쇄 매뉴얼 호환성)

**Q3. 색상이 다른 박스(파란/초록)를 추가로 쓰고 싶습니다.**
A. 표준에서 벗어나는 색은 사용하지 마세요. 정 필요하면 PM 에게 표준 추가 제안.

**Q4. 한글 폰트가 깨져 보입니다.**
A. Windows 11 기본 폰트(Malgun Gothic) 또는 Noto Sans KR 로 통일하세요.

**Q5. 캡처를 다시 찍어야 할 일이 자주 생깁니다.**
A. UI 가 자주 바뀌는 단계에서는 캡처를 미루고, **UI 안정화 후 일괄 캡처**하는 것을 권장합니다.

## 부록 — placeholder 처리

매뉴얼 작성 시점에 실제 스크린샷이 아직 준비되지 않은 경우, 마크다운 본문에는 경로만 적어두고 실제 PNG 파일은 추후 추가합니다.

```markdown
![로그인 화면 전체](../screenshots/00-시작/01-login-full.png)
```

> 위와 같이 작성해두면 PNG 파일이 추가되는 즉시 매뉴얼에 자동 표시됩니다. 누락된 PNG 는 별도 Issue 로 추적합니다.
