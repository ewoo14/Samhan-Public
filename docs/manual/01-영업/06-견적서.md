## 1. 현재 견적서 운영 (P2-1 fix 전 우회)

### 1-1. 현재 상태

- desktop 어플에 [견적서] 메뉴 부재
- backend `slip-service` 는 `OUTBOUND` 슬립의 status `DRAFT` 를 견적과 유사하게 사용 가능 (단, 정식 견적 status 분리 X)
- 정식 견적서 = legacy v4 webview 일부 운영 중 (외부 도메인 — 임시)

### 1-2. 임시 우회 (현재 운영자 절차)

1. **방법 A — slip DRAFT 활용 (권장)**
   - [01-영업/03. 슬립 발행](03-슬립-발행.md) 의 슬립 신규 → DRAFT 단계로 저장
   - 단가 / 라인 입력 후 [임시저장] (SAVED 까지 갈 필요 없음)
   - 출고전표 인쇄 (`print/DispatchView.tsx`) 로 거래처에 견적 형태로 송부 — 단, "견적" 문구 부재 (P2-1 fix 시 정식 view)
   - 거래처 confirm 후 → SAVED → SENT → 정식 슬립 진행

2. **방법 B — legacy v4 webview**
   - `https://order.samhan-air.com/quote` (legacy 도메인 — Phase 11 cutover 시 제거 예정)
   - 외부 견적서 양식 사용
   - 본 시스템과 동기화 X — 운영자가 수동 슬립 발행 필요

3. **방법 C — Excel 견적서 (현재 가장 일반)**
   - 회사 표준 Excel template 으로 견적 작성
   - 거래처에 PDF 변환 후 메일 송부
   - 거래처 confirm 후 본 시스템 슬립 발행

## 4-1. 수정 이력 보기 (Phase 12 step-4c, PR-H4c FE rollout)

> **PR-H4c 변경** — P2-1 fix 후 정식 견적서 (`SlipDetailPage` 의 `QUOTE_*` status 또는 별도 `QuoteDetailPage`) 도입 시 본 절의 audit overlay 가 자동 적용됩니다. 본 절은 시드 패턴 (PR-H2 `02-출고-처리.md` § 2-9) 의 견적 도메인 적용 — slip 화면과 시각 1:1 동일.

### 4-1-1. 견적서 헤더 "수정 N회" badge

QuoteDetailPage (또는 SlipDetailPage 의 `QUOTE_DRAFT` status) 우측 상단에 **수정 N회** badge 표시.

### 4-1-2. 필드별 audit overlay (단가 / 라인 / 메모 / 만료일)

각 필드 우측에 가장 최근 변경:

```
단가              12,000원              ~~10,000원~~        ● 오영업 13:32 (단가 협상)
라인 수량         100 EA                ~~50 EA~~           ● 오영업 13:30
메모              긴급 출고 (마감 전)    ~~오전 배송~~       ● 오영업 13:32
만료일            2026-06-09             (시드)
```

### 4-1-3. QUOTE_DRAFT 자유 수정 → QUOTE_SENT 잠금

견적이 `QUOTE_DRAFT` (작성 중) 인 경우 자유 수정. `QUOTE_SENT` (거래처 발송 완료) 후에는 LOCKED_REQUIRES_APPROVAL — 수정 요청 워크플로우 (PR-H3 시드 패턴):

```
[잠금 banner — QUOTE_SENT 이후]
이 견적은 잠금 상태입니다 — 수정 요청을 보내주세요.
거래처 발송 후 단가 / 수량 변경 시 권한자 (MANAGER) 승인 필요.

[+ 수정 요청]
```

### 4-1-4. QUOTE_ACCEPTED FULLY_LOCKED

거래처가 견적을 confirm (`QUOTE_ACCEPTED`) 한 직후부터는 직접 수정 불가:

```
[잠금 banner]
이 견적은 완전 잠금 상태입니다 — 수정 견적을 발급해 주세요.
거래처 confirm 후 단가 변경 시 신규 견적 + 거래처 재confirm 절차 필요.
```

### 4-1-5. UUID 비공개 + 견적번호 노출

화면 어디에도 UUID 노출 0건. 비즈니스 식별자만 표시:

- 견적번호 (`Q-2026-0510-001` — P2-1 fix 시 정식 부여) / 거래처명 (사업자명)
- actorName 풀네임 + 색상 dot

### 4-1-6. 1초 SSE 실시간 sync

영업 다수가 동일 견적을 수정하는 경우 1초 안에 동기화 (단가 협상 충돌 방지).

```
[우측 상단 toast]
실시간 변경 감지 — 0.8초
오영업 님이 단가 를 "12,000원" 으로 수정했습니다. (rev #4)
```

> 본 절은 P2-1 fix PR 머지 후 정식 견적서 화면 도입 시 자동 적용. 본 PR-H4c FE rollout 으로 사전 가이드만 시드.
