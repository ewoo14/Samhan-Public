## 대상 독자

- 영업팀(SALES) — 본인 담당 거래처 조회
- 영업 관리자(MANAGER) — 전체 거래처 조회
- 회계팀(ACCOUNTANT) — 거래처별 매출/매입 / 여신 history 조회
- 사전 준비: [01. 거래처 등록](01-거래처-등록.md) 또는 시드 데이터 50건 (`PARTNER_SEED_TEST_DATA=true`) 존재

## 이 매뉴얼에서 배울 내용

1. 거래처 list 화면 진입 + 검색 (이름 / 사업자번호 / 거래처코드)

3. 단건 상세 보기 (4 탭 — 일부 미구현)

5. 신용 이력 (credit-history) 조회

## 2. 검색

### 2-1. 검색창

화면 상단의 검색창에 아래 중 하나를 입력하면 즉시 필터링됩니다.

| 검색 키워드 | 입력 예 | 매칭 컬럼 |
| --- | --- | --- |
| 거래처코드 | `P-2026-0001` | `partner_code` exact |
| 상호 (전체/부분) | `데모`, `(주)` | `business_name` LIKE |
| 사업자등록번호 | `123-45-67890` | `business_number` exact (자동 포맷) |
| 검색창내용 (V2 컬럼) | `강남`, `HVAC` | `search_keywords` LIKE |
| 담당자 | `박영업` | `contact_person` LIKE |

![거래처 검색창](../screenshots/01-영업/02-partner-search-box.png)

### 2-2. 필터 (상태)

- **활성** (기본) — soft-delete 안된 거래처
- **삭제** — 휴지통 (MASTER 만 조회 가능)

> ⚠️ **복합 필터 미구현 (P1-6)** — 거래처그룹 / 거래유형 / 지역별 동시 필터는 미지원. 현재는 단일 키워드 검색만.

## 5. 상세 보기 (단건)

목록에서 거래처코드 / 상호 클릭 → 상세 다이얼로그 표시.

### 5-1. 4 탭 상세 (일부 미구현)

상세 화면은 [01. 거래처 등록](01-거래처-등록.md) 의 4 탭 구조와 동일합니다. 단, **현재 상세 dialog UI 미구현 (P0-6)** 으로 backend API (`GET /admin/partners/{partnerCode}`) 만 가능합니다.

![거래처 상세 4 탭](../screenshots/01-영업/02-partner-detail-tabs.png)

### 5-2. Backend API 직접 호출 (임시 우회)

```http
GET /admin/partners/P-2026-0001
Authorization: Bearer <MASTER/MANAGER/SALES/ACCOUNTANT JWT>
```

응답에 4 탭 모든 필드가 포함됩니다.

## 6. 매출/매입 내역 조회

거래처별 슬립 발행 history 조회. **현재 partner-service 에는 없고 slip-service `/internal/slips/by-partner-code/{partnerCode}/recent` 호출 필요**.

### 6-1. UI 위치 (예정)

- 거래처 상세 → `[매출 내역]` 탭 (P2-4 — 미구현)
- 거래처 상세 → `[매입 내역]` 탭 (P2-4 — 미구현)

### 6-2. 임시 우회 — 슬립 메뉴에서 거래처 필터

[03. 슬립 발행](03-슬립-발행.md) 화면 → 슬립 목록 → 거래처 필터에 `P-2026-0001` 입력 → 해당 거래처 슬립만 조회.

## 7. 신용 이력 (credit-history)

여신한도 변경 / 수금/지급 history.

### 7-1. Backend endpoint

```http
GET /admin/partners/P-2026-0001/credit-history
Authorization: Bearer <MASTER/MANAGER/ACCOUNTANT JWT>
```

응답: `PartnerCreditHistory` 시계열 (변경 일자 / 변경 전후 한도 / 변경자 / 사유).

### 7-2. UI 위치 (예정)

거래처 상세 → `[여신 history]` 탭 (P0-6 와 함께 추가 예정).

## 9. FAQ + 트러블슈팅

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| 검색해도 거래처가 안 나옴 | 시드 데이터 미적재 | `PARTNER_SEED_TEST_DATA=true` 설정 후 재시작. IT 관리자 문의 |
| 본인이 등록한 거래처가 목록에 없음 | F5 새로고침 미수행 | F5 |
| 상세 클릭 시 빈 다이얼로그 | 상세 dialog UI 미구현 (P0-6) | Backend API 우회 (§5-2) |
| `403 Forbidden` | ROLE 권한 부족 (예: SALES 가 다른 영업담당 거래처 조회) | MANAGER 에게 권한 요청 |
| 사업자등록번호 검색 시 결과 없음 | 형식 불일치 (`-` 누락) | `123-45-67890` 형식으로 정확히 입력 |
| 페이지네이션이 너무 느림 | DB index 미설정 (V2 검색키워드 GIN index 누락 — P1-7) | 개발팀에 index 추가 요청 |
| 한글 검색이 일부만 매칭 | LIKE 검색 한계 (full-text search 미적용) | 더 짧은 키워드로 시도 |
