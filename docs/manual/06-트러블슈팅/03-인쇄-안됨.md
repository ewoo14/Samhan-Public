## 2. 거래명세서 미구현 (P0-4)

### 2-1. 증상

- 슬립 상세 → [거래명세서 인쇄] 클릭 → "구현 예정" 토스트
- 또는 legacy v4 양식이 출력되나 회사 로고 / 거래처명 / 합계가 부정확

### 2-2. 우회

1. **출고전표로 대체** — `print/DispatchView.tsx` (✅ 구현) 출력 후 거래처에 수기 부가 정보 첨부
2. **legacy v4 export** — 슬립 상세 → 우상단 [legacy 인쇄] (P0-4 부분 구현 — 임시)
3. **Excel export** — 슬립 라인을 Excel 로 export 후 거래처에 별도 송부 (P1-6 일부)

### 2-3. 정식 fix (P0-4 PR)

`feedback_print_design_iteration.md` 의 3~5회 iteration 의무 — 사용자 이미지 → mock → Edge 캡처 → CSS-only 미세 조정.

## 3. 세금계산서 미구현 (P0-4)

### 3-1. 증상

- 메뉴 [회계 → 세금계산서] 자체가 없음 (UI / backend 모두 부재)
- 거래처가 "세금계산서 보내주세요" 요청 시 다른 시스템 사용

### 3-2. 우회 (현재 운영)

회계 직원이 외부 e-Tax (NTS Hometax) 시스템에서 직접 발행:
1. https://www.hometax.go.kr 접속
2. 본 회사 공인인증서 로그인
3. 전자세금계산서 발행 → 거래처 사업자번호 + 합계 + 부가세 입력
4. 발행 후 본 시스템 슬립의 비고란에 "세금계산서 발행: yyyy-MM-dd hometax.go.kr" 메모

### 3-3. 정식 fix (P0-4 PR — Phase 11 진입 전 권고)

- accounting-service 에 `TaxInvoiceController` 신규
- `print/TaxInvoiceView.tsx` 양식 (한국 국세청 표준 양식 + 부가세 자동 계산)
- e-Tax NTS Hometax API 연계 (장기 backlog — Phase 11 후)

## 4. Edge 인쇄 설정 (한글 깨짐 / 여백)

### 4-1. 증상

- 인쇄물에 한글이 ㅁㅁㅁ 또는 빈 사각형
- 회사 로고가 빠진 채 출력 (백그라운드 그래픽 OFF)
- 페이지 끝에서 라인이 잘림

### 4-2. Edge 인쇄 다이얼로그 표준 설정

인쇄 미리보기 화면 (Ctrl+P) 에서:

| 설정 | 권장 값 | 이유 |
| --- | --- | --- |
| **프린터** | OS 등록된 프린터 | (PDF 저장 시 "Microsoft Print to PDF") |
| **방향** | 세로 (Portrait) | 출고전표 / 거래명세서 표준 |
| **용지 크기** | A4 | (영수증은 88mm — 미구현) |
| **여백** | 기본 | 우리 인쇄 양식이 여백 포함 디자인 |
| **배율** | 100% | 자동 맞춤은 한글 폰트 깨짐 가능 |
| **페이지당 페이지 수** | 1 | (분할 인쇄 X) |
| **양면 인쇄** | 단면 | (거래처 보존 표준) |
| **컬러** | 컬러 | (회사 로고 + 도장 색상 보존) |
| **추가 설정 → 백그라운드 그래픽** | ✅ 체크 | 회사 로고 / 표 배경색 누락 방지 |
| **추가 설정 → 머리글 / 바닥글** | ❌ 해제 | URL / 페이지 번호 자동 추가 방지 |

### 4-3. 폰트 미설치 시 한글 깨짐

→ [02. 화면 표시 안됨](02-화면-표시-안됨.md) §5 참조.

## 5. 인쇄 미리보기가 안 뜸

### 5-1. 증상

- [인쇄] 버튼 클릭 → 아무 일도 일어나지 않음
- popup blocker 알림이 잠깐 뜸
- 새 창이 열렸다가 즉시 닫힘

### 5-2. 원인 + 해결

| 원인 | 해결 |
| --- | --- |
| popup 차단 | Edge 주소창 우측 차단 아이콘 → 팝업 허용 |
| Electron print API 가 새 창 미생성 | 어플 재시작 / 어플 캐시 삭제 |
| OS 기본 프린터 미설정 | 설정 → 프린터 및 스캐너 → 기본 프린터 추가 |
| Adobe PDF / 네트워크 프린터 응답 없음 | 다른 프린터 (Microsoft Print to PDF) 로 변경 후 재시도 |

## 6. 페이지 잘림 / 여백 문제

### 6-1. 증상

- 우측 column 이 잘림
- 마지막 라인이 다음 페이지로 밀림
- 라인 사이 간격이 너무 넓거나 좁음

### 6-2. 원인 + 해결

| 원인 | 해결 |
| --- | --- |
| 슬립 라인 수가 1 페이지 초과 (보통 25 라인 이상) | 페이지 분할 표준 — 자동. 깨지면 라인 묶음 분할 발행 |
| 사용자 폰트 크기 변경 (CSS zoom) | 인쇄 다이얼로그에서 배율 100% 강제 |
| 회사 로고 이미지 누락 | `print/assets/logo.png` 누락 — 어플 재설치 |
| 여백 자동 맞춤 (인쇄 다이얼로그) | "기본" 으로 변경 |

## 7. 인쇄 후 거래처에 보낼 때 (운영 절차)

### 7-1. 출고전표

- 1 부 거래처 (배송 시 기사가 전달)
- 1 부 본 회사 보관 (월말 마감용)
- 본 시스템 슬립 라인이 모바일 서명 ([04-모바일/02. 전자 서명](../04-모바일/02-전자-서명.md)) 후 자동 DELIVERED 전이

### 7-2. 거래명세서 (P0-4 fix 후)

- 거래처에 PDF 첨부 메일 또는 우편
- 본 회사 회계 보관용 1 부

### 7-3. 세금계산서 (외부 e-Tax 우회)

- 거래처 사업자번호로 e-Tax 자동 송부 (e-Tax 표준)
- 본 회사 회계 시스템에 발행번호 메모

## 8. FAQ

**Q1. 인쇄가 항상 흑백으로 출력됩니다.**
A. 인쇄 다이얼로그 → 컬러 설정 변경 + 프린터 자체 설정 (드라이버) 확인.

**Q2. PDF 로 저장할 수 있나요?**
A. 인쇄 다이얼로그 → 프린터 = "Microsoft Print to PDF" 선택 → 저장 위치 지정.

**Q3. 모바일에서 인쇄 가능한가요?**
A. 미구현. 모바일은 SMS / 카톡으로 거래명세서 PDF link 전송 (P3 backlog).

**Q4. 인쇄 미리보기와 실제 출력이 다릅니다.**
A. 프린터 드라이버 설정 (배율 / 여백 자동 맞춤) 영향. Edge 인쇄 → 프린터 드라이버 설정에서 "맞춤" → "100%" 변경.

**Q5. 영수증 (88mm 폭) 으로 인쇄하고 싶습니다.**
A. P0-4 미구현 — 양식 자체 부재. Phase 11 후 P3 backlog (88mm 영수증 view + 분기).

**Q6. 거래명세서가 영문으로 출력됩니다.**
A. legacy v4 양식이 영문 일부 — P0-4 fix 시 한국어 표준화 (`feedback_print_design_iteration.md` iteration 진행).

**Q7. 세금계산서를 본 시스템에서 발행 가능한가요?**
A. 미구현 (P0-4). 외부 e-Tax (NTS Hometax) 직접 발행. Phase 11 진입 전 P0-4 fix 시 본 시스템 통합 검토.
