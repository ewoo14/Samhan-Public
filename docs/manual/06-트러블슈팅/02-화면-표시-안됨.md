# 06-트러블슈팅 / 02. 화면 표시 안됨 (Stage 3)

> **대상 독자**: 모든 desktop / Electron 사용자 + IT 관리자
> **소요 시간**: 5~10분 자가 진단
> **연관 매뉴얼**: [00-시작하기/02. 메인 화면](../00-시작하기/02-메인-화면.md)

---

## 이 매뉴얼에서 다루는 증상

1. Vite / Electron 시작 실패 — `npm run dev` 가 빠르게 종료
2. 빈 화면 (white screen) — Electron 창은 열렸으나 내용 없음
3. 일부 메뉴 누락 — ROLE 정상이고 다른 사용자는 보이는데 본인만 안 보임
4. Network 오류 (axios) — `Network Error` / `ERR_CONNECTION_REFUSED`
5. 스타일 깨짐 / 한글 깨짐
6. 무한 로딩 spinner

---

## 1. Vite / Electron 시작 실패

### 1-1. 증상

- desktop 어플 더블클릭 → 잠시 후 자동 종료
- 개발 환경에서 `npm run dev` → `Error: ...` 표시 후 종료
- Electron splash screen 만 잠깐 보이고 사라짐

### 1-2. 진단

#### 운영자 — 어플 사용 중

1. 작업관리자 → SamhanPublic 프로세스 강제 종료
2. 다시 실행 → 같은 증상 반복 시 IT 관리자 연락

#### 개발자 / IT 관리자

```bash
cd clients/desktop
npm install
npm run dev
```

오류 로그 확인 — 흔한 원인:
- `EADDRINUSE: address already in use :::5173` → Vite port 충돌, 다른 process kill
- `Cannot find module 'electron'` → `npm install` 재실행
- `Failed to fetch dynamically imported module` → Vite cache 손상, `rm -rf node_modules/.vite` 후 재실행

### 1-3. 해결

1. 어플 완전 종료 (작업관리자 SamhanPublic 강제 종료)
2. 어플 폴더 → 캐시 삭제 (`%APPDATA%/SamhanPublic/Cache`)
3. 재실행
4. 미해결 → 어플 재설치 (IT 관리자가 설치 파일 배포)

---

## 2. 빈 화면 (white screen)

### 2-1. 증상

- Electron 창은 열렸는데 흰색 또는 회색만 보임
- 메뉴 / 사이드바 완전 부재
- F12 (개발자 도구) 열어도 콘솔에 빨강 오류

### 2-2. 진단 — F12 콘솔 확인

| 콘솔 메시지 | 원인 | 해결 |
| --- | --- | --- |
| `Failed to load resource: net::ERR_CONNECTION_REFUSED` | Vite dev server 다운 또는 production build 의 `dist/` 누락 | 어플 재시작 / 재설치 |
| `Uncaught SyntaxError: Unexpected token '<'` | API 응답이 HTML (404 페이지) — Gateway 다운 | IT 관리자 |
| `Failed to fetch http://api.samhan-air.com/...` | 백엔드 다운 또는 네트워크 차단 | §4 Network 오류 참조 |
| `localStorage is not available` | 사이트 데이터 차단 | Edge 설정 → 쿠키 / localStorage 허용 |
| (콘솔 비어있음) | JS bundle 자체 미로드 | `dist/` 폴더 손상 — 재설치 |

### 2-3. 해결

1. F5 (새로고침) — Vite dev mode HMR 일시 오류 시 즉시 복구
2. Ctrl+Shift+R (강력 새로고침) — 캐시 무시
3. F12 → Application 탭 → Storage → Clear site data
4. 어플 종료 후 재시작
5. 미해결 → IT 관리자에게 F12 콘솔 스크린샷 + 시간 보고

---

## 3. 일부 메뉴 누락 (본인만 안 보임)

### 3-1. 증상

- 동료 PC 에서는 메뉴가 보이는데 본인 PC 에서만 안 보임
- 사이드바의 일부 항목이 회색 또는 숨김
- 클릭 시 "권한 없음" 토스트

### 3-2. 진단

가장 흔한 원인 = **JWT 캐시** (이전 ROLE 의 token 보유 중).

1. 화면 우상단 본인 이름 클릭 → ROLE 표시 확인 ([03. 역할별 권한](../00-시작하기/03-역할별-권한.md) §2 매트릭스 대조)
2. ROLE 이 잘못 표시 → JWT 갱신 필요
3. ROLE 정상인데 메뉴 누락 → 사이드바 컴포넌트 권한 mapping 버그 (개발팀 보고)

### 3-3. 해결

1. 로그아웃 → 재로그인 (90% 케이스 해결)
2. localStorage clear → 재로그인
3. 어플 완전 종료 → 재시작 (Electron cache 가 token 보유 중일 수 있음)
4. 미해결 → IT 관리자에게 ROLE 변경 (MASTER 만 가능)

## 4. Network 오류 (axios `Network Error`)

### 4-1. 증상

- 화면은 정상인데 데이터 list 가 비어있음
- 토스트 "Network Error" 또는 "ERR_CONNECTION_REFUSED"
- F12 Network 탭에 빨강 (failed) 요청

### 4-2. 진단 (운영자)

1. 인터넷 연결 — `https://google.com` 접속 가능?
2. 회사 VPN 사용 중인 경우 — VPN 연결 상태?
3. 어플 우상단 [상태] 인디케이터 확인 (P3 backlog — 현재 미구현. 임시: F12 → Network)

### 4-3. 진단 (IT 관리자)

```bash
# Gateway 핑
curl -I http://api.samhan-air.com/actuator/health

# 특정 service 핑
curl -I http://api.samhan-air.com/auth/actuator/health
curl -I http://api.samhan-air.com/slips/actuator/health
```

응답 200 = 정상, timeout / 5xx = backend 다운.

### 4-4. 해결

| 원인 | 해결 |
| --- | --- |
| 인터넷 끊김 | 네트워크 복구 후 새로고침 |
| VPN 끊김 | VPN 재연결 |
| 회사 방화벽 변경 (Samhan Public 도메인 차단) | IT 관리자에게 방화벽 화이트리스트 요청 |
| Gateway 다운 | IT 관리자 → docker-compose restart api-gateway |
| 특정 service 다운 (예: slip-service 만) | IT 관리자 → 해당 service 재시작 |
| Eureka 미발견 (service registration 지연) | 30초~2분 대기 후 재시도 |

## 5. 스타일 깨짐 / 한글 깨짐

### 5-1. 증상

- 폰트가 영문체로 표시 (Noto Sans KR 미적용)
- 한글이 ㅁㅁㅁㅁ 또는 빈 사각형
- 레이아웃이 어긋남 (CSS 미적용)

### 5-2. 원인 + 해결

| 원인 | 해결 |
| --- | --- |
| Noto Sans KR 시스템 미설치 | Windows: `https://fonts.google.com/noto/specimen/Noto+Sans+KR` 다운로드 → 설치 |
| OS locale 이 ko-KR 아님 | 설정 → 시간 및 언어 → 한국어 우선 |
| 어플 dist/ 의 font 파일 손상 | 어플 재설치 |
| Edge 인쇄 미리보기 시 깨짐 | 인쇄 다이얼로그 → "백그라운드 그래픽" 체크 → "기본 글꼴" 변경 |
| OS 표시 배율 (DPI) 이 125% 이상 | 설정 → 디스플레이 → 100% 변경 (Electron CSS rem 기준) |

## 6. 무한 로딩 spinner

### 6-1. 증상

- 화면 진입 시 spinner 만 회전 (10초 이상)
- 결국 toast "Network timeout"
- F5 새로고침 해도 같음

### 6-2. 원인

- backend API 가 응답 시간 5초 초과 (대량 데이터 / 느린 query)
- DB lock (다른 사용자가 같은 row update 중)
- Eureka discovery 지연

### 6-3. 해결

1. 다른 화면 진입 → 정상이면 특정 화면만 문제 → 데이터량 (예: 슬립 list 의 from-to 기간) 좁혀서 재시도
2. 모든 화면 spinner → backend 다운 — IT 관리자
3. 다른 사용자도 같은 증상 → service 전체 장애 — IT 관리자 / 개발팀

## 7. F12 개발자 도구 활용

### 7-1. 콘솔 (Console) 탭

- 빨강 오류 — 클릭 후 stack trace 확인
- 노랑 경고 — 보통 무시 가능
- 콘솔 출력을 IT 관리자에게 보고 시 우클릭 → "Save as..." 로 파일 저장

### 7-2. 네트워크 (Network) 탭

- F12 → Network 탭 → 화면 새로고침 → 모든 HTTP 요청 표시
- 빨강 (failed) / 4xx / 5xx 요청 클릭 → Headers / Response 확인
- 특히 `/auth/me` (본인 정보) / `/slips` 등 핵심 endpoint 응답 시간 확인

### 7-3. 응용 프로그램 (Application) 탭

- Storage → Local Storage → token / role 확인
- "Clear site data" 로 모든 캐시 / 쿠키 / localStorage 삭제 (재로그인 필요)

## 8. FAQ

**Q1. 어플이 갑자기 "응답 없음" 으로 멈췄습니다.**
A. 작업관리자 → SamhanPublic 강제 종료 → 재시작. 반복 시 IT 관리자.

**Q2. 어플이 자동 업데이트되지 않습니다.**
A. P3 backlog (auto-update). 현재는 IT 관리자가 새 설치 파일 배포 → 운영자 재설치.

**Q3. desktop 어플과 동시에 브라우저에서 같은 계정 로그인 가능?**
A. 불가 — single session. 새 로그인이 기존 token 무효화. 사용자 분리 권장.

**Q4. 사이드바 너비를 조정할 수 있나요?**
A. 미구현 (P3 backlog). 현재 250px 고정.

**Q5. 다크 모드 지원되나요?**
A. 미구현. CSS dark 변수만 일부 작성, 토글 부재 (P3).

**Q6. 화면 일부가 잘립니다.**
A. 화면 해상도 / 배율 — Windows 디스플레이 100% 권장. 1920x1080 이상 해상도에서 최적.

**Q7. 모바일에서 desktop 어플을 사용할 수 있나요?**
A. desktop = Electron 만 — 모바일 미지원. 모바일은 RN Expo 어플 (mobile-staff) 별도.
