## 4. 본문

### 4-1. 정식 매출 마감 화면 미구현 안내

P2-4 슬라이스로 Phase 11 후 출시 예정입니다. 본 화면이 출시되면 다음 기능이 제공됩니다.

- 거래처별 매출 합계 자동 집계
- 미수금 잔액 자동 표시
- 결제 조건(현금/30일/익월말 등) 별 만기 알림
- Excel export

### 4-2. 우회 1 — 회계 거래처원장 활용

1. ACCOUNTANT 로 로그인
2. 좌측 사이드바 **[회계]** > **[보고서]** > **[거래처원장]** 진입
3. 거래처 / 기간 선택
4. 매출 / 매입 / 잔액 자동 표시
5. Excel 다운로드 (P1-6 미구현 — 화면 인쇄 우회)

자세한 절차는 [03-회계 / 02. 보고서](../03-회계/02-보고서.md) 참조.

### 4-3. 우회 2 — 영업 + 회계 합동

월말 정산 시.

1. **영업 부장** — 슬립 list 에서 기간/거래처 필터 → 매출 합계 확인
2. **회계 직원** — 분개 list 에서 거래처/기간 필터 → 입금 확인
3. 양측 데이터 비교 → 불일치 시 즉시 보정
4. Excel 양식에 정리 → 거래처에 발송

### 4-4. Phase 11 후 정식 본문 교체

P2-4 PR 머지 시 본 placeholder 는 정식 본문으로 교체됩니다.

## 6. FAQ

**Q1. 거래처별 미수금은 어디서 보나요?**
A. 회계 [03-회계 / 02. 보고서](../03-회계/02-보고서.md) 의 거래처원장에서 잔액 확인.

**Q2. 매출 마감 후 변경 사항 발생 시?**
A. 회계 분개 수정 + 슬립 취소(CANCELED) 처리. 영업 부장 + 회계 직원 협의.

**Q3. 정식 화면은 언제?**
A. P2-4 슬라이스로 Phase 11 후 출시 예정.

**Q4. Excel export 가능한가요?**
A. 회계 보고서 화면에서도 P1-6 미구현. 임시로 화면 인쇄(PDF 변환) 우회.
