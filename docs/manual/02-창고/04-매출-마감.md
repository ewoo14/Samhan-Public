## 2. 임시 우회 (현재 운영 절차)

### 2-1. 일별 마감 우회 (회계 직원 수동)

1. **매일 17:00** — slip list 화면 진입 (`/slips`)
2. 필터 — 발행일 = 오늘 / status = `DELIVERED`
3. 각 슬립 클릭 → [정산 (CONFIRMED)] (회계 권한 필요)
4. 자동 분개 생성 확인 — `/accounting/journals` 진입
5. 시산표 (`/accounting/balances`) 매출 (400번대) 합계 검증
6. 일별 매출 = 회사 표준 Excel 양식에 수기 기록

> ⚠️ 모든 슬립을 한번에 confirm 하는 일괄 작업은 미구현. 슬립 1건당 1회 클릭.

### 2-2. 월별 마감 우회

1. **월말 (말일 17:00)** — 일별 마감을 모두 완료한 후
2. 시산표 (`/accounting/balances?period=2026-05`) 월별 진입
3. 매출 / 매출원가 / 판관비 합계 확인
4. 손익 계산 = Excel 수기 (P0-1 미구현 — 손익계산서 / 재무상태표 부재)
5. 거래처별 미수금 = 거래처 list 화면 → 거래처별 매출 - 결제 수기 계산

### 2-3. 단가 자동 우회

- 거래처별 단가그룹 미구현 (P2-4) → 영업 직원이 슬립 발행 시 매번 수동 단가 입력
- 단가 검산 = 회계 직원이 슬립 라인별 검토 (실수 위험)

### 2-4. 부가세 자동 우회

- 슬립 라인 합계 × 10% = 부가세 (수동 계산)
- 회계 직원이 분개 시 수동 입력 (차변 부가세 / 대변 매출)
- 외부 e-Tax (NTS Hometax) 별도 발행 (P0-4 미구현 우회)

## 3. 정식 fix 계획 (Stage 4 — P2-4)

### 3-1. P2-4 PR 권고 범위

```
1. slip-service:
   - 슬립 status 에 CLOSED 추가 (CONFIRMED → CLOSED — 마감 후 변경 차단)
   - 일별 일괄 confirm endpoint (`POST /slips/batch-confirm?date=2026-05-09`)

2. accounting-service:
   - 일별 / 월별 마감 endpoint (`POST /accounting/closings/daily`, `/monthly`)
   - 마감 후 분개 자동 생성
   - 마감 reverse endpoint (역분개 + audit)

3. partner-service:
   - 거래처 단가그룹 도메인 (`PartnerPriceGroup`)
   - 단가 자동 적용 (slip 발행 시 partner-service lookup)

4. dashboard-service:
   - 거래처 통합 view (월별 매출 / 미수금 / 결제 시계열)

5. desktop UI:
   - [매출 마감] 메뉴 (사이드바 → 회계 → 마감)
   - 일별 마감 화면 (날짜 선택 + 슬립 list + [일괄 확정] 버튼)
   - 월별 마감 화면 + 자동 시산표 + 미수금 정리
```
