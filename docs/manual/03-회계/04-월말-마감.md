# 03-회계 / 04. 월말 마감 (Stage 3)

> ⚠️ **구현 상태** — ❌ **미구현** (P2-4 #4 매출 마감 / 정산 + P2-3 #5 결산 마감 lock). 본 docs 는 **임시 대응 안내** 목적.
>
> **현재 본 시스템 — 월말 마감 기능 없음**:
> - ❌ 매출 마감 (P2-4 #4 — 영업 도메인)
> - ❌ 결산 마감 lock (P2-3 #5 — 회계 도메인, 마감 후 분개 입력 차단)
> - ❌ 월말 자동 분개 (감가상각 / 기말재고 평가 / 충당금 / 외화환산)
> - ❌ 월말 시산표 자동 snapshot (P2-3 #2 전기/당기 비교 의존)
> - ❌ 마감 보고서 일괄 생성 (시산표 + 재무상태표 + 손익계산서 ZIP / PDF)
>
> **현 시점 대처** — 수기 마감 절차 + 외부 ERP 활용. P2-3 / P2-4 fix PR (Phase 11 후 3개월 내 권고) 머지 후 정식 사용 가능.

---

## 대상 독자

- 회계팀(ACCOUNTANT) — 월말 결산 / 마감 / 보고서 작성
- 영업 관리자(MANAGER) — 매출 마감 (영업측)
- 회사 대표 / MASTER — 월말 결과 확인 / 승인
- 사전 준비: 월중 모든 슬립 CONFIRMED + 분개 POSTED

---

## 1. 향후 구현 예정 기능 (P2-3 + P2-4)

P2-3 / P2-4 fix PR 머지 후 본 시스템에서 사용 가능할 기능:

### 1-1. 매출 마감 (영업측, P2-4 #4)

> ⏳ **구현 예정** — MANAGER 가 월말에 [매출 마감] 버튼 클릭 → 해당 월 슬립 일괄 잠금 (status 추가 변경 차단).

| 기능 | 동작 |
| --- | --- |
| 월별 매출 합계 자동 집계 | 슬립 status=CONFIRMED 월별 합계 |
| 거래처별 매출 합계 | 거래처 통합 view (P2-4 N3 의존) |
| 부서별 / 담당자별 매출 | 매출 분석 (P2-3 #3 의존) |
| 마감 후 슬립 status 변경 차단 | DB lock + 한국어 에러 |
| 정산 (수금) 내역 매칭 | 분개 102 보통예금 vs 110 외상매출금 자동 매칭 |

### 1-2. 결산 마감 lock (회계측, P2-3 #5)

> ⏳ **구현 예정** — ACCOUNTANT/MASTER 가 [회계 마감] 버튼 클릭 → 해당 월 분개 입력/수정/역분개 일괄 차단.

| 기능 | 동작 |
| --- | --- |
| 월별 분개 잠금 | 마감 후 신규 DRAFT / POST / REVERSE 차단 |
| 마감 해제 (MASTER 만) | 잠금 해제 시 audit 로그 의무 |
| 자동 분개 발생 시 거부 | 슬립 CONFIRMED 가 마감된 월에 발생 시 한국어 에러 |
| 마감 status 컬럼 | `JournalPeriodStatus` (OPEN / CLOSED) 신규 도메인 |

### 1-3. 월말 자동 분개 (P2-3 #4 보강)

> ⏳ **구현 예정** — 매월 말일 자동 batch 분개 생성.

| 자동 분개 | 차변 | 대변 | 비고 |
| --- | --- | --- | --- |
| 감가상각 | 818 감가상각비 | 142 건물 (또는 감가상각누계액) | 월할 / 정액법 |
| 충당금 (대손) | 835 대손상각비 | 외상매출금 차감 계정 | 잔액의 N% 자동 |
| 외화환산 (해당 시) | 환산이익 / 환산손실 | 외화 자산/부채 | 월말 환율 적용 |
| 기말재고 평가 (필요 시) | 매출원가 | 재고자산 | inventory-service 연계 |

> ⚠️ 현재는 `JournalSeeder` ADJUSTMENT 패턴으로 시드만 존재 (5건 — `JournalSeeder` §pickSpec). 정식 batch 자동화는 P2-3 fix.

### 1-4. 마감 보고서 일괄 생성 (P0-1 fix 후 보강)

> ⏳ **구현 예정** — [월말 보고서 생성] 버튼 → 17 보고서 (시산표 + 재무상태표 + 손익계산서 + 분개장 + 원장 + 매출장 + 매입장 + 부가세신고 자료) PDF/Excel 일괄 export.

P0-1 17 보고서 fix 가 선행 필요 ([02. 재무 보고서](02-보고서.md) §3-1).

## 2. 현 시점 임시 대응 (수기 절차)

> 본 절은 **P2-3 / P2-4 fix PR 머지 전** 까지 한정 적용되는 임시 절차입니다. 매월 말일 ~ 익월 5일 사이에 회계담당자가 수동으로 진행.

### 2-1. Step 1 — 매출 마감 (영업, 익월 1~3일)

영업 관리자(MANAGER) 가 진행:

1. [01-영업/03. 슬립 발행](../01-영업/03-슬립-발행.md) 슬립 목록 → 기간 = `해당 월` 필터
2. status = SAVED / SENT / ACCEPTED / PROCESSING / INSPECTING / COMPLETED / SHIPPING / DELIVERED 인 미처리 슬립 점검
3. 익월 마감 전 가능한 모든 슬립을 CONFIRMED 로 전이 의뢰 (회계담당)
4. 미처리 슬립은 다음 월로 이월 (수기 메모 — Excel 보관)

### 2-2. Step 2 — 회계 분개 점검 (회계, 익월 1~5일)

회계담당자가 진행:

1. [01. 분개 입력](01-분개-입력.md) 분개 목록 → 기간 = `해당 월` + status = `DRAFT` 검색
2. 모든 DRAFT 분개를 검토 후 POSTED 처리 또는 정정 / 폐기
3. 자동 분개 (출처 = SLIP) 가 슬립 CONFIRMED 건수와 일치 확인 — 누락 시 IT 관리자에게 service health 확인 의뢰
4. 월말 자동 분개 수기 입력:
   - 감가상각: 차변 818 / 대변 142 (정액법 월할)
   - 대손충당금: 차변 835 / 대변 외상매출금 차감 계정 (회사 정책 %)
   - 기타 결산 정리 분개 (회사 회계 정책에 따라)

### 2-3. Step 3 — 시산표 검증 (회계, 익월 3~5일)

[02. 재무 보고서](02-보고서.md) §2 시산표 조회 후:

1. 차변 합계 == 대변 합계 ✅ 확인
2. 자산(100) / 부채(200) / 자본(300) / 수익(400) / 비용(800) 카테고리별 합계 검증
3. 전월 시산표 (Excel 보관본) 와 비교하여 비정상 변동 점검
4. 100 보통예금 잔액 == 실 통장 잔액 (월말 기준) 일치 확인
5. 110 외상매출금 잔액 == 거래처별 미수금 합계 (수기 집계) 일치 확인

### 2-4. Step 4 — 보고서 작성 (회계, 익월 5~10일)

[02. 재무 보고서](02-보고서.md) §3-3 임시 대응 (외부 ERP / Excel 수기) 절차로:

1. 재무상태표 (B/S) — 자산 / 부채 / 자본 시산표 합계로 작성
2. 손익계산서 (P/L) — 매출 / 매출원가 / 판관비 / 영업이익 / 당기순이익
3. 자금일보 / 자금현황표 — 102 보통예금 일별 추이
4. 거래처별 매출/매입 / 채권/채무 잔액분석 — 거래처별 110/외상매입금 잔액

### 2-5. Step 5 — 부가세 신고 (분기말만, 1/4/7/10월)

분기말에만 진행 ([03. 세금계산서](03-세금계산서.md) §2-4):

1. 시산표 220 부가세예수금 잔액 확인 (분기 합계)
2. 매입 부가세 (있는 경우) 확인
3. Hometax 부가세 신고서 수기 입력 또는 외부 ERP 사용
4. 신고 완료 후 220 부가세예수금 → 보통예금 납부 분개

### 2-6. Step 6 — 마감 lock 수기 운영

본 시스템은 마감 후 분개 입력 차단 기능이 없으므로, **수기 운영**:

1. 마감 완료 일자를 회계담당자가 사내 위키 / Excel 에 기록
2. 마감된 월에 신규 분개 입력이 필요하면 MASTER 승인 의뢰 (audit log 의무)
3. 마감 후 발생한 자동 분개 (슬립 CONFIRMED) 는 **다음 월** 로 이동 분개 (수기 정정 분개)

> ⚠️ **회계 audit 의무** — 마감 후 임의 분개 수정은 한국 외부감사법 위반 가능. 수정 시 반드시 역분개 + 사유 기록 + MASTER 승인.

## 3. 월말 마감 체크리스트

월말 마감 시 회계담당자가 확인할 항목:

| # | 항목 | 확인 방법 |
| :-: | --- | --- |
| 1 | 모든 슬립 CONFIRMED | 슬립 목록 status 필터 |
| 2 | 모든 분개 POSTED | 분개 목록 status 필터 |
| 3 | 자동 분개 수 == 슬립 CONFIRMED 수 | 분개 목록 출처=SLIP 카운트 |
| 4 | 시산표 차/대 일치 | [02. 보고서](02-보고서.md) §2 |
| 5 | 보통예금 잔액 == 통장 잔액 | 시산표 102 vs 통장 |
| 6 | 외상매출금 잔액 == 거래처 미수금 합계 | 시산표 110 vs 수기 집계 |
| 7 | 외상매입금 잔액 == 거래처 미지급금 합계 | 동일 |
| 8 | 부가세예수금 잔액 == 매출 부가세 합계 | 시산표 220 vs 매출 합계 × 10% |
| 9 | 월말 자동 분개 수기 입력 | 감가상각 / 대손 / 결산정리 |
| 10 | 외부 ERP / Hometax 와 매출 합계 일치 | 외부 매출장 비교 |
| 11 | 마감 일자 사내 위키 기록 | 수기 |
| 12 | 보고서 export 후 회사 대표 보고 | Excel / PDF |

| --- | --- | --- |
| 사이드바에 [회계] → [월말 마감] 메뉴가 없음 | 미구현 (P2-3 #5 / P2-4 #4) | §2 임시 절차 사용 |

| 시산표가 익월 1일에 자동 snapshot 안 됨 | 미구현 (P2-3 #2 전기/당기 비교 의존) | 매월 말일 시산표 화면 → Excel export 보관 |
| 마감 보고서 PDF 일괄 생성 안 됨 | 미구현 (P0-1 fix 후 추가) | §2-4 수기 작성 |
| 부가세 신고서 자동 생성 안 됨 | 미구현 (P0-1 #4 = 14 보고서 중) | [03. 세금계산서](03-세금계산서.md) §2-4 Hometax 직접 |
| 외부 ERP 사용 시 이중 분개 위험 | 외부 ERP 와 본 시스템 양쪽 분개 | 마감 시 합계 비교 의무 (체크리스트 §3 #10) |
| 회사 대표가 월별 손익 추이 요청 | 월별손익분석 (P0-1 #5) 미구현 | 시산표 3개월 Excel 합산 |
| 결산일 변경 (회계연도 시작월 변경) | 미구현 — 1월 시작 고정 | 회사 회계 정책 1월 시작 유지 권고 |
