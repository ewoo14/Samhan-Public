- 회계팀(ACCOUNTANT) — 시산표 / 재무제표 조회 / 인쇄

### 3-2. 임시 대응 — backend API 직접 호출

P0-1 fix 전까지는 다음 endpoint 만 사용 가능:

```http
GET /accounting/balances?period=202605
Authorization: Bearer <ACCOUNTANT 또는 MASTER JWT>
```

**응답 예** —
```json
{
  "period": "202605",
  "rows": [
    {"accountCode": "110", "accountName": "외상매출금",
     "totalDebit": 33000000, "totalCredit": 5500000, "balance": 27500000},
    ...
  ],
  "totalDebit": 41100000,
  "totalCredit": 41100000
}
```

### 3-3. 임시 대응 — 외부 회계 프로그램 (Excel / 이카운트 / Hometax)

복잡한 보고서 (재무제표 / 손익계산서 / 부가세 신고) 는 P0-1 fix 전까지:

1. 시산표 결과를 화면에서 복사 → Excel 붙여넣기
2. 한국 일반기업회계기준 양식에 직접 매핑 (자산 / 부채 / 자본 / 수익 / 비용)
3. 또는 외부 ERP (이카운트, 더존 SmartA) 로 분개 export 후 보고서 재생성
4. 부가세 신고서는 국세청 Hometax 직접 입력 (P3-2 #1 e-Tax 연계 미구현)

> ⚠️ **이중 입력 위험** — 외부 ERP 사용 시 본 시스템 분개와 이중 입력될 수 있음. P0-1 fix 후 정식 보고서로 전환 권고.

## 5. FAQ + 트러블슈팅

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| 사이드바에 [회계] → [보고서] 메뉴가 없음 | desktop UI 미구현 (P0-1) | UI fix 후 재시도. 임시 — backend API 직접 호출 |
| 시산표 합계 mismatch | DRAFT 분개 누락 / 외부 데이터 import 오류 | 분개장에서 DRAFT 검색 → POSTED 처리 |
| 월별 시산표가 비어 있음 | 해당 월에 POSTED 분개 없음 | [01. 분개 입력](01-분개-입력.md) 으로 분개 추가 또는 시드 적재 |
| 분기/년 누적 시산표 필요 | 미구현 (P2-3 #1) | 월별 시산표 3개를 Excel 합산 |
| 전기 비교 (전월/전년) 필요 | 미구현 (P2-3 #2) | 동일 |
| 부서별 손익 필요 | 미구현 (P2-3 #3) | Phase 11 후 |
| 손익계산서 / 재무상태표 필요 | 미구현 (P0-1 #16/#17) | §3-3 외부 ERP 또는 Excel 수기 |
| 부가세 신고서 (NTS Hometax) | 미구현 (P3-2 #1 e-Tax 연계) | Hometax 직접 입력 |
| 인쇄 시 한글 깨짐 | 폰트 미설치 | Noto Sans KR 시스템 설치 |
| MANAGER 가 보고서 접근 불가 | 권한 — ACCOUNTANT/MASTER 만 | 본인 ROLE 확인 |
