### 통과 항목

- **영문/기술 용어 잔존 없음**: 4 PNG 전체 헤더·라벨 한국어 확인 (주문서 수정 / 주문서 재확인 / 수정 이력 / 거래처 권한 화면).
- **Modal 적용 정상**: edit form 은 DS `Modal(size="xl")` + `Button(variant="primary/secondary")` 정확히 사용.
- **Select 적용**: 라인 내 구분 Select — DS `Select` 컴포넌트 정상 사용.
- **status badge 토큰 정합**: `statusDraft/Confirmed/Sent/Canceled` 모두 `var(--state-*)` CSS 변수 참조. SP-08-4-1 lesson 반영 확인.
- **SP-08-4-1 회고 회피**: footer/DOM 내 `내부 식별자` 노출 패턴 없음. `actorId` 는 화면 미노출(`actorName` 만 표시).
- **UUID 비공개 가드**: URL 파라미터 `:id` 는 `orderNumber`(비즈니스 식별자) decode 후 사용. `id` 자체를 UI 에 출력하는 경우는 `orderNumber` 미수신 시 fallback 뿐이며, orderNumber 는 UUID 아님.
- **충돌 배너**: 409 conflict 시 DS `Button(variant="secondary")` 내 한국어 CTA "최신 내용 불러오기" — 기술 용어 없음.
