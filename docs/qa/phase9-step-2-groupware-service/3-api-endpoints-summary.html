groupware-service — REST endpoint matrix

Phase 9 W2 (port 8092 / DB groupware_db) — 결재선 + 메신저 + 일정. ServiceDiscoveryClient 두 번째 소비자 (W1 partner-service 첫 소비자), UserClient → user-service Internal API.

Internal endpoint = X-Internal-Token + ROLE_MASTER (InternalTokenFilter, /internal/** prefix 한정 — PR #91 fix 패턴)
