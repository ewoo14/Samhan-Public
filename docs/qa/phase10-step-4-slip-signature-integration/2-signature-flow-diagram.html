2. 3 path slice-accent 색상

success Path 1 — 양쪽 저장 성공 (slipBridged=true)
driver-app sign → arologis signatures INSERT (cell D) → SlipResolver resolveByPartnerCode → SlipClient findRecentSlipIdByPartnerCode (200, slipId 반환) → SlipClient registerSignature → slip-service /internal/slips/{id}/signatures (cell B) → 응답 slipBridged=true
pending Path 2 — 매핑 실패 graceful fallback (slipBridged=false)
driver-app sign → arologis signatures INSERT (cell D 정상) → SlipResolver → slip-service by-partner-code (200 + data=null, partner-service 매핑 실패) → SlipClient registerSignature 미호출 → 응답 slipBridged=false (UX 시각화 — slice-accent-pending 배지)
deferred Path 3 — slip-service down 또는 timeout (graceful fallback)
driver-app sign → arologis signatures INSERT (cell D 정상) → SlipResolver → slip-service 5xx / timeout (DV-1 connect 2s / read 3s) → SlipClient Optional.empty → registerSignature 미호출 또는 false → 응답 slipBridged=false + warn log (Phase 11 cutover 시 재동기화 가능)
