3. 핵심 정규표현식 + heuristic

HEADER       = ^(\d+)일착\s*(.+?)입니다\s*$
VEHICLE_HDR  = ^(\d+)\.\s*(.*)$
TONNAGE      = ^(\d+(?:\.\d+)?)톤\s*$           // 우선 매칭 — "1.4톤" 이 vehicle hdr 로 오인되는 경로 차단 (W10-1 fix)
STOP         = ^[-–]\s*([^()]+)\(([^()]+?)-(\d+)\)(.*)$

heuristic:
  1. 헤더 1회 추출 (LocalDate 기준 가까운 월 추정)
  2. TONNAGE 우선 매칭 (currentVehicleSeq != null 일 때)
  3. VEHICLE_HDR + 첫 정차 동시 처리 ("2. -경기..." 같은 single-line vehicle 호환)
  4. 미해석 라인 → unparsed=true + rawText 보존
  5. 추가 group label ("상일상차" / "초월상차") status=UNPARSED + parsedAddress=null
