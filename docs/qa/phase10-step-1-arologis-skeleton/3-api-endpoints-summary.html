2. Admin API (JWT + ROLE_MASTER/MANAGER)

MethodPath책임활성채널

GET /admin/arologis/dispatches?date=&type= Dispatch 목록 조회 (날짜 + 유형 필터) W10-1 Admin
GET /admin/arologis/dispatches/{id} Dispatch 상세 조회 — vehicles + stops + driverCode 포함 W10-1 Admin
POST /admin/arologis/dispatches/{id}/auto-match 자동 매칭 — 활성 DriverMatcher 호출 + assignedDriverId 반영 + 알림 trigger W10-1 (Mock) Admin
POST /admin/arologis/dispatches/{id}/vehicles/{seq}/match-external 특정 차량 외부 매칭 trigger (W10-2 시점 단건 매칭으로 분리) W10-2 활성 Admin
POST /admin/arologis/dispatches/{id}/vehicles/{seq}/assign-driver 수동 기사 배정 — driverCode 로 lookup → vehicle.assignDriver(MANUAL) W10-1 Admin
PUT /admin/arologis/dispatches/{id}/vehicles/{seq}/stops/{stopSeq}/status 정차 상태 갱신 (ARRIVED / DELIVERED / FAILED) W10-1 Admin
GET /admin/arologis/drivers?source=&phoneNumber=&appInstalled= Driver 목록 조회 (source / phoneNumber / appInstalled 필터) W10-1 Admin
PUT /admin/arologis/dispatches/{id}/delete Dispatch Soft Delete (BaseEntity.markDeleted) W10-1 Admin

3. Driver-app API (JWT + ROLE_DRIVER, W10-3 활성)

MethodPath책임활성채널
