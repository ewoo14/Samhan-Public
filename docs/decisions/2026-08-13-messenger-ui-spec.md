# 사내 메신저 화면 정본 (개발책임자 지시)

> 2026-08-13 · 이슈 `#894` · PR `#1201` 후속 슬라이스

지시 원문을 그대로 구조화한 것입니다. **추론해서 채운 곳은 없습니다.** 안 적힌 것은 아래 §4 에 질문으로 남깁니다.

---

## 1. 상단 전환 — `개별` / `그룹별`

**좌측 상단에 버튼 2개.** 이 둘로 페이지를 바꿉니다.

```
┌──────────────────────────────┐
│ [개별] [그룹별]              │   ← 좌측 상단
├──────────────────────────────┤
│ (선택된 페이지 내용)          │
└──────────────────────────────┘
```

---

## 2. `개별` 페이지

```
┌──────────────────────────────────────┐
│ [개별] [그룹별]                       │
├──────────────────────────────────────┤
│ ● 나          홍길동    부장          │   ← 내 상태 아이콘 · 이름 · 직책
├──────────────────────────────────────┤
│ ● 김대표      김대표    대표          │   ← 대표부터
│ ● 이이사      이이사    이사          │   ← 직급 순
│ ○ 박부장      박부장    부장          │
│ ● 최과장      최과장    과장          │
│ …                                     │
└──────────────────────────────────────┘
```

### 규칙

```
① 대표부터 시작해 직급별로 정렬한다
② 각 직원은 상태 아이콘 + 이름 + 직책 으로 표시한다
③ 내 정보(상태 아이콘·이름·직책)가 직원 리스트 위에 온다
④ 직원을 클릭하면 말을 걸 수 있고, 그때 대화창이 생성된다
⑤ 🚨 대화 기록은 보존한다
```

### 접속 상태 아이콘

> **데스크탑이든 모바일이든 하나 이상 접속 시 아이콘이 `접속` 으로 나온다.**

⟹ 기기별로 따로 보여 주지 않고, **어느 기기든 하나라도 붙어 있으면 접속**입니다.

## 3. `그룹별` 페이지

```
┌──────────────────────────────────────┐
│ [개별] [그룹별]                   🔍  │   ← 우측 상단 돋보기
├──────────────────────────────────────┤
│ ● 나          홍길동    부장          │   ← 개별과 동일하게 내 정보가 위
├──────────────────────────────────────┤
│ 영업2팀 단톡방                    ③   │   ← 안읽음 먼저
│ 회계 마감 공유방                  ①   │
│ 물류 배차                             │   ← 그 다음 최신순 내림차순
│ 개발팀                                │
│ …                                     │
└──────────────────────────────────────┘
```

### 규칙

```
① 내 상태 아이콘·이름·직책이 위에 온다 (개별 페이지와 동일)
② 그 아래는 카카오톡 단톡방 리스트처럼 보인다
③ 안읽은 메시지 숫자를 카카오톡처럼 표시한다
④ 🚨 정렬 — 안읽음이 먼저, 그 다음은 최신순 내림차순
⑤ 어떤 단톡방인지 알 수 있게 나온다
```

### 우측 상단 돋보기 🔍

```
클릭 → 모달
        · 검색
        · 복수 선택
        · 단톡방 생성
```

## 4. ⏳ 지시에 없어 확인이 필요한 것

**지어내지 않고 남깁니다.**

```
① 상태 아이콘의 가짓수
   "접속" 외에 자리비움·부재중·오프라인이 있는가
   🔑 S4(부재중)가 별도 슬라이스로 잡혀 있어 그때 정해도 되는지 확인 필요

② 직급 정렬의 정본
   "대표부터 직급별" 의 직급 순서가 어디에 정의돼 있는가
   (기존 권한/직책 마스터를 쓰는가, 별도 순서표가 필요한가)

③ 동일 직급 안에서의 정렬
   이름순인가, 입사순인가, 정해진 것이 없는가

④ 퇴사자·비활성 계정 표시 여부

⑤ "단톡방이 어떤 단톡방인지" 의 표시 방식
   방 이름을 쓰는가, 참여자 이름을 나열하는가(카카오톡은 이름이 없으면 참여자 나열)

⑥ 개별 페이지에서 이미 대화 기록이 있는 직원의 표시
   마지막 메시지·안읽음 수를 함께 보여 주는가, 이름·직책만 보여 주는가
```
