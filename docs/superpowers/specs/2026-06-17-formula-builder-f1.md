# F1 스펙: 품목 분류(대/중분류) 동적 + 품목별 설정 + 고정DC% (수식 빌더 에픽 1차)

> 2026-06-17 개발책임자 F1 착수 + 정정: **카테고리별 대분류(catL)/중분류(catM)도 품목별 설정 + 분류 사용자 추가/삭제(동적)**. **개발책임자 확인 필요**.

## 1. 목표
GAS에 이미 있는 옵션(판넬변경·리모컨·유연호스·발통·분기관·360원형/사각)이 **품목 분류/세부설정** 기반으로 작동하도록 품목 도메인 확장. + 변동DC 옆 **고정DC %단위**(품목별, 기초값=시트). **분류는 고정 enum이 아니라 동적 마스터**(사용자 추가/삭제).

## 2. 분류 체계 (개발책임자 정정 핵심)
- **EstimateCategory = 고정**(홈멀티/싱글중대형/상업멀티/구형) — 가격 결정·탭, 슬1에서 동적화 폐기 결정 유지.
- **catL(대분류) / catM(중분류) / catS(소분류) = 동적 3단계 계층**(사용자 추가/삭제, 대분류 → 맞는 중분류 → 맞는 소분류) — **카테고리별**, 품목별 설정.
  - 예) catL=판넬 → catM=공청/WIFI/미내장/인피니트/360/일반 → catS=360원형·360사각 / 소형·중형·대형 등
  - catL=리모컨 → catM=유선/무선 → catS=모델 세부
  - catL=자재/부자재 → catM=유연호스/발통/분기관/받침대/필터 → catS=원형발통·일자발 등
  - catL=실내기/실외기 → catM=1Way/4Way/360CST → catS=소형·중형·대형
  - **실내기 종속**=판넬/리모컨/유연호스, **실외기 종속**=받침대/필터(둘 다 세트 수량 따라 자동 수량 전개 대상)
- 즉 **2축**: EstimateCategory(고정) ⊥ catL/catM(동적). a8ab 정찰의 GAS `catL`/`catM`(품명 정규식 분류)을 동적 마스터로 승격.

## 3. 데이터 모델
- **Classification 마스터**(신규): `id`, `estimate_category`(**카테고리별 필수** — 페이지별 따로 설정, 개발책임자 확정), `cat_level`(L/M/S **3단계**), `parent_id`(catM→catL, catS→catM **계층**), `name`, `display_order`, `active`. → 사용자 CRUD(추가/삭제/순서, 계층 — 부모 분류 선택 시 자식만 노출).
- **🚨 모든 설정 = 페이지(카테고리)별**: 분류 catL/catM/catS·고정DC%·변동DC·옵션·수량 전부 카테고리(홈멀티/싱글중대형/상업멀티/구형) 스코프. 견적품목 관리의 카테고리 탭마다 독립 설정.
- **Product**: `cat_l_id` / `cat_m_id` / `cat_s_id`(Classification FK, 품목별) + `fixed_discount_rate`(numeric %, 품목별). V20.
- 기초값(시트): ProductSheetSyncService가 GAS 품명 정규식(`classifyHome_`/`classifyCommercial_` 포팅)으로 catL/catM 자동 분류 → 마스터에 없으면 자동 생성(seed) + 고정DC% 시트 적재.

## 4. 옵션 작동 (F1은 토대, 옵션 UI는 F3)
- GAS 옵션(판넬변경 등) = catL/catM 기반 선택지. 예: '판넬변경' → catL=판넬 품목 중 catM 선택. '360판넬 원형/사각' → catM=360원형/360사각.

## 5. UI (F1-b) — 가독성: 기능별 메뉴 분리 + 카테고리 탭 + 점진적 노출 (개발책임자 우려 2026-06-17)
- **견적품목 관리**(기존): 품목별 **핵심 컬럼만** — 분류(catL/catM/catS) + 고정DC% + 변동DC. 상세(옵션·수량)는 행 '설정' 버튼 → 드로어/모달(점진적 노출).
- **분류 관리 메뉴**(신규): catL/catM/catS 계층 트리 CRUD(좌측 트리 + 우측 상세 마스터-디테일, 카테고리 탭). 대→중→소 단계 노출.
- (후속 메뉴) **가격/수식 설정**(카테고리별 DC율·VAT·배분), **번들/옵션 설정**(매칭 룰·수량비율) — 별도 메뉴로 분리해 한 화면 과밀 방지.
- 모든 메뉴: 카테고리(홈멀티/싱글중대형/상업멀티/구형) 탭. EstimateCategory 탭 고정.

## 6. GAS parity 🚨
- 분류 기초값 = GAS 품명 정규식 분류(동일 규칙).
- 고정DC% 기초값 = 시트.
- parity 회귀: GAS 품명 분류 vs DB catL/catM 분포 일치 + 고정DC% 일치.

## 7. 슬라이스
- **F1-a (BE)**: Classification 마스터 DB(V20)+CRUD API + Product catL/catM FK·고정DC% + ProductSheetSyncService 분류·고정DC% sync + parity 회귀 IT.
- **F1-b (FE)**: 견적품목 관리 catL/catM·고정DC% 컬럼 + 분류 관리 메뉴(추가/삭제/순서).
