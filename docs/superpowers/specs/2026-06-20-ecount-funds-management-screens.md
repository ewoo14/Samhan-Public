# spec(draft): eCount 회계 메뉴 갭 — 「자금 관리」 모듈 (#3, 개발책임자 화면 캡처 정의)

> 2026-06-20. 개발책임자가 회계 메뉴 갭("~13건")을 **eCount 실 화면 캡처를 순차 제공**하여 정의. 본 문서는 수신 화면을 누적 기록(순차 진행 중 — 추가 화면 대기). 모두 우리 복식부기 `journals` + 통장계좌/거래처/계정과목에서 파생되는 **읽기 전용 집계 보고서**.

## 공통
- 헤더: 회사명 `(주)삼한공조시스템`, 기간 필터, 결재란(담당/과장/대표 스탬프 — PrintLayout 결재란 재사용).
- 데이터 출처: accounting `journals`(POSTED 복식부기) + 통장계좌 master(MIG-6) + 거래처(partner) + 계정과목(chart of accounts).
- 음수 잔액 거래처(임시/선수) 표시 허용.

## 수신 화면 (배치 1, 2026-06-20)

### 1. 자금일보 (Daily Funds Report)
- 기간 예: 2026/01/20~2026/06/20.
- **§1 자금 현황**: 계정명 × 거래처명(은행계좌별) × [이월잔액(외화)/증가(외화)/감소(외화)/금일잔액(외화)]. 계정 그룹: 현금 / 보통예금(국민·기업·신한·우리·하나 등 계좌별) / 장기금융상품(확정급여형DB) / 단기차입금(대출 건별 만기·금리 표기) / 장기차입금. 계정별 **소계** + 전체 **합계** 행.
- §2 자금의 증가(아래 별도 화면) 연결.

### 2. 자금의 증가 (Funds Increase Detail)
- 자금일보 §2 — 일자 / 상대계정명(외상매출금·미수금) / 상대거래처명 / 적요 / 금액. 자금 증가 분개 라인 drill-down.

### 3. 현금흐름 (입출금내역, Cash Flow)
- **2기간 비교**(예 2026/05/20~06/20 vs 2026/05/19~06/19), 단위 원.
- 기초잔액 / **증가**(계정별: 외상매출금·미수금·직원급여(판)·지급수수료(판)·운반비(판)·이자수익) **소계** / **감소**(외상매입금·미지급금·예수금·직원급여(판)·복리후생비(판)·접대비-일반(판)·통신비(판)·세금과공과금(판)·보험료(판)·수도광열비(판)·지급수수료(판)·운반비(판)·이자비용) **소계** / 기말잔액.

### 4. 자금현황표 (Funds Status Table)
- 기간 예: 2026/05/21~06/20. 계정명 × 거래처 × [이월잔액/증가/감소/금일잔액(외화)]. 컬럼별 **필터(▼)**. 계정 그룹: 현금 / 보통예금(계좌별) / 단기대여금 / 외상매출금(거래처별, 임시 거래처 음수 포함). 계정별 소계.

### 5. 자금증감내역 (Funds Change Detail)
- 자금현황표 §1 자금의 증가 — 일자 / 상대계정명 / 상대거래처명 / 적요 / 금액. drill-down.

## 구현 메모 (잠정)
- 자금일보 ≈ 자금현황표(기간만 다른 동일 골격) — 공용 자금현황 쿼리 + 기간 파라미터로 통합 가능.
- 증가/증감내역 = 자금현황의 증가측 분개 라인 drill-down(공용).
- 현금흐름 = 계정별 증감 집계 + 2기간 비교.
- 우선 BE: 자금현황 집계 쿼리(계정×거래처×기간 이월/증가/감소/잔액) — journals 기반. FE: 회계 메뉴 「자금 관리」 하위 4화면 + 결재란 인쇄.
- ⚠️ 추가 화면 수신 후 전체 스코프 확정 → 슬라이스 분해.

## 수신 화면 (배치 2, 2026-06-20) — 손익/채권/집계

### 6. 월별손익분석 (Monthly P&L Analysis)
- 기간 예: 2026/01/01~06/30. 손익계산서 계정명 × **월(2026년 1~6월) × 집계(합계)**.
- 구조: 1.매출(상품매출) / 2.매출원가(상품매출원가) / 3.매출총이익 / 4.판매비및일반관리비(직원급여·잡급·복리후생비·여비교통비·카드접대비·접대비·통신비·소모품비·세금과공과금·지급임차료·수선비·보험료·차량유지비·수도광열비·지급수수료·광고선전비·외주용역비·판매촉진비·운반비·판매수수료·잡비) / 5.영업손익 / 6.영업외수익(이자수익·수입임대료·법인세환급액·잡이익) / 7.영업외비용(이자비용·잡손실) / 8.법인세비용차감전순손익 / 9.법인세비용 / 12.당기순이익.
- **기존 손익계산서(income statement)의 월별 분해 변형** — 기존 IncomeStatement 리포트 + 월별 GROUP BY.

### 7. 채권잔액분석표 (Receivables Balance Analysis)
- 거래처별 외상매출금. 컬럼: 담당자코드/담당자/거래처코드/거래처명/**여신한도**/순채권/**받을어음**/외상매출금계/**외상매출금 현황(월별 aging: 6월·5월·4월·3월·기타)**/**수금계획 현황(6·7·8·9월·기타)**/잔액/은번/모바일/전화. 컬럼 필터(▼). 임시/개인 거래처 음수 잔액 포함.
- **기존 partner-aging(슬1, /accounting/reports/partner-aging) 확장** — 추가: 여신한도(credit limit, partner master), 받을어음(notes receivable), 월별 aging 버킷, 수금계획(collection plan — 신규 입력 데이터?), 담당자/연락처. ⚠️ 수금계획은 신규 입력 도메인일 수 있음(확인 필요).

### 8. 회계집계표 (Accounting Summary / 시산표류)
- 기간 예: 2026/05/21~06/20. 계정 × [이월잔액/차변/대변/금액]. 전 계정(출자금·현금·보통예금·단기대여금·외상매출금·미수금·선급금·가지급금·부가세대급금·선납세금·상품·장기금융상품·...·외상매입금·미지급금·예수금·부가세예수금·...·상품매출·상품매출원가·직원급여(판)·...·이자비용·잡손실). 합계 행.
- **시산표(trial balance)와 동형** — 기존 시산표/합계잔액시산표 리포트와 정합/확장 확인 필요.

## 종합 분류 (배치1+2, 8화면)
- **신규(자금관리 모듈)**: 자금일보·자금의증가·현금흐름·자금현황표·자금증감내역 (5) — journals+통장계좌 파생.
- **기존 확장**: 월별손익분석(손익계산서 월별), 채권잔액분석표(partner-aging+여신/받을어음/수금계획), 회계집계표(시산표).
- ⚠️ 잠재 신규 입력 도메인: **수금계획(collection plan)**, **받을어음(notes receivable)**, **여신한도(credit limit)** — 단순 조회가 아니라 입력/관리 필요 시 별도 도메인.

## 수신 화면 (배치 3, 2026-06-20) — 원장/분개장/일·월계표/거래처

### 9. 계정별원장 (Account Ledger)
- 계정(출자금/현금/보통예금/...) 별 페이지. 전표번호/거래처/적요/차변/대변/잔액 + 이월잔액. → ✅ **기존 LedgerController(/accounting/ledgers) + AccountingReportController(/accounting/journals/ledger-data) 보유**.

### 10. 분개장 (Journal)
- 전표번호 × 계정명/거래처명/차변금액/대변금액/적요. → ✅ **기존 JournalController(/accounting/journals) 보유**.

### 11. 월계표 (Monthly Trial Balance)
- 차변(합계/대체/현금출금)/계정명/대변(현금입금/대체/합계). 월계 합. → ✅ **기존 AccountSummaryLine/DailyBreakdownLine(월계표) 보유**.

### 12. 일계표 (Daily Trial Balance)
- 동형(일계/금일전일/합계). → ✅ **기존 DailySummaryController(일계표) 보유**.

### 13. 거래처거래내역조회 (Partner Transaction History)
- 거래처별 일자-No/적요/차변/대변/합계. → ✅ **기존 AccountingDocumentSearchController(/ledgers/partners/search) 보유**.

## 슬라이스 분해안 (제안)
- **슬A. 자금관리 모듈** (신규, 최대): 자금현황 집계 service(계정×거래처×기간 이월/증가/감소/잔액, journals+통장계좌) → 자금일보·자금현황표(기간만 차이) + 증가/증감내역 drill-down + 현금흐름(계정별 증감 2기간). 회계 메뉴 「자금」 하위.
- **슬B. 월별손익분석**: 기존 손익계산서 service + 월별 GROUP BY 컬럼.
- **슬C. 채권잔액분석표**: partner-aging 확장 — 채권/채무 방향 토글 + 여신한도(partner master)·받을어음·월별 aging 버킷·수금계획. ⚠️ 수금계획/받을어음/여신한도가 **신규 입력 데이터면 별도 도메인 슬라이스 선행**(개발책임자 확인 필요).
- **슬D. 결재란 config**: 보고서 인쇄 결재란(담당/과장/대표) — MASTER+위임매니저 설정. cross-cutting(PrintLayout 결재란 + 권한).
- 기존 보유(원장/분개장/일·월계표/시산표/거래처내역)는 화면 IA 정합(회계 메뉴 배치)만.

## 수신 화면 (배치 5, 2026-06-20) — 합계잔액시산표/전표현황

### 17. 합계잔액시산표 (Trial Balance — totals + balances)
- 기말잔액(차변)/기말금액(차변)/계정명/기말금액(대변)/기말잔액(대변). 표준 4컬럼(차변 합계·잔액, 대변 합계·잔액). → 🔁 **기존 시산표(BalanceSheetController) 확장/정합** — 합계+잔액 4컬럼 표준판.

### 18. 전표현황 (Voucher Status / 회계거래현황)
- 전표번호 × 거래유형(**입금보고서·지출결의서(매입)·매출전표 I·매입전표·일반전표**) × 금액 × 거래처명 × 적요. 거래처별 그룹 + 일자/월계 소계 변형. → ⚠️ **신규성 확인**: 전표 통합 조회(매출/매입/입금/지출/일반 전표 cross-type 목록).

### 19. 입/출금계좌 조회 (Bank Deposit/Withdrawal → 거래처 매칭 → 회계 반영)
- **목록**: 일자/구분(입금·출금)/계좌번호/계좌명(은행)/거래처코드/거래처명/입금처(출금처)/금액/회계전표. 탭 **전체·미반영·회계반영·강제회계반영**. 기간 필터, 페이지네이션, Search(F3).
- **워크플로우**(개발책임자 설명):
  1. 통장 입출금내역 수집(통장등록 — KFTC/통장 import).
  2. **자동 거래처 매핑**: 입금처/출금처 명 기반 규칙으로 거래처 자동 매핑(매핑조회).
  3. **수동 지정**: 거래처명 필드에 **autocomplete 로 거래처 입력·선택**.
  4. **입출금보고서 작성**: 선택(클릭)한 내역에 한해 보고서 작성 → **해당 거래처 원장(거래내역=journal) 반영**(회계전표 생성).
  5. 미반영→회계반영 상태 전이(강제회계반영 옵션).
- → 🆕 **트랜잭션 워크플로우**(read-only 아님). 기존 직결: **DepositMatchService(입금매칭)** + **KftcClient(은행)** + **통장계좌 master** + journal 전기. ⚠️ 기존 deposit-match 커버 범위 갭-매핑 필요(자동매핑 규칙·autocomplete 지정·보고서→원장 전기·미반영/반영 탭).
