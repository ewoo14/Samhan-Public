## 6. 환경 메모

- **standalone 라이브QA 는 다운스트림 URL 주입이 관건** — host 에서 Docker 내부 서비스에 직접 못 닿는다. **publish 된 포트**를 가리킬 것. 이걸 놓쳐 QA 2건이 `불러오지 못했습니다` 만 띄웠다.
- standalone 포트 사용 이력: `18386 18387 18390 18391 18392 18419 18420 18486`
- `VITE_APP_VERSION` (`YYYY/MM/DD-N`) 미주입 시 renderer 런타임 사망
- `design-system` junction 깨지면 `dist` 빌드 + `npm install`
- **Flyway 번호는 적용된 최고 버전보다 높게** — `slip_db` 는 `V100` 이 적용돼 있어 `V62` 가 배포본 기동을 막을 뻔했다(`#984` V27 과 같은 모양). `out-of-order` 는 기본값 `false`. 현재 `slip-service` 는 `V102`, `auth-service` 는 `V91` 까지.
- `accounting-service` 전체 테스트는 **일곱 라운드 연속 300초대 timeout** — 권위는 CI
- 공유 `partner_auth_db` 에 `V3` 가 적용돼 있다(QA 하네스 부작용). **`V3` 파일 수정 시 checksum 으로 죽는다.**
